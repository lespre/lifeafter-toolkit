### 2.1 CDN 资源库 / 本地还原树 —— 板级自定义展示视图
用户拍板采纳推荐组合：**CDN = 目录组折叠（主）+ 全量表格（辅）**；**还原树 = 模块索引（主）+ 仅概览（辅）**。
明确**不做**的（避免猜数）：CDN 档位矩阵（缺分档体积）、还原树目录树（路径仅一层，组件成本最高）。

| 交付点 | 实现 |
|---|---|
| 视图切换 | `?view=xxx` + `curView()/setView()`，写进 URL 可分享，非法值回退默认 |
| 切换器 UI | `buildViewSwitch()` + `VIEW_OPTS`，挂在 `board.html` 的 `#viewSwitch` |
| 统一筛选 | `viewFilterItems()`（证据等级 `#fEv` + `meta.filters` 自定义 + 搜索框 `#q`），与通用渲染路径同口径 |
| 检索性能 | `cdnHay()` / `treeHay()` 预构建检索串，避免 33,601 次 `JSON.stringify` |
| CDN 视图 | `cdnGroupRender()`（10 目录组折叠 + 体积条 + 6 概览卡）、`cdnTableRender()`（711×9 可排序表）、`cdnPackTable()` 组内明细表 |
| 还原树视图 | `treeIndexRender()`（概览 + 分布条 + 1,090 模块索引）、`treeDashRender()`（仅概览）；`TREE_MOD_CAP=200` 分页；`hidden`+`dataset.built` 惰性展开 |
| 样式 | `board_base.css` 追加 `body.view-mode` 段 129 行，颜色全走 `var(--token)` |

**实测数据**：CDN 概览 = 逻辑包 711 / 文件卷 1,650 / 条目 4,537,324 / 变体合计 **164.1 GB** / 本地已下载 **50.6 GB** / 完整 77·部分 2·未下载 632。
