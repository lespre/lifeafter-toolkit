## 铁律

| 规则 | 说明 |
|---|---|
| **`41_还原树` 是唯一权威** | 一切资源读取都从这里；不要用老工作副本或旧快照 |
| **索引先于查询** | 任何"找资源"之前先确认 `10_索引/indexes` 是新的 |
| **可重建 ⇒ 不入库** | 本目录全部可重建，仓库只留骨架 |
| **临时区可弃** | `90_临时` 随时清；重要产物要挪到 `20_提取` / `30_分析` |

---

## 怎么重建

```bash
toolkit_cli.py index build          # ① 建索引
toolkit_cli.py materialize          # ② 物化还原树（硬链接，幂等）
toolkit_cli.py bulk <目标> --out 03_执行/20_提取/   # ③ 批量提取
toolkit_cli.py verify               # ④ 自检
```

> **数据来源铁律**：拆包数据**一律从 `41_还原树` 读**；
> 新热更用 `hotfix apply --real` 就地增补进树，不要另开工作副本。

详见 [../docs/USAGE.md](../docs/USAGE.md)。
