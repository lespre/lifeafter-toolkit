# 用 Agent 快速接手本项目

面向 AI Agent（Claude Code / Codex / Hermes / Cursor 等）的**冷启动手册**。
目标：一个没有任何上下文的 Agent，读完这份就能**安全地干活，且不重复踩坑**。

## 0. 30 秒了解这是什么

《明日之后》客户端资源**解码 · 定位 · 复原 · 可视化**工具链。

**核心能力 = 「定位」+「渲染」**：把一个游戏内资源从海量容器里**精确定位出来**，
再**按游戏产物原样渲染/呈现**。

覆盖范围（不限于）：**时装** · **武器皮肤** · **奖池/活动** · 场景/展示台 ·
武器/装备 · 音效/特效 · 配置表/图集。

★ **有测试服源 ⇒ 可定位未上线内容**（测试服先于正式服下发新皮肤/新时装/新奖池；
可做正式服 vs 测试服 fid 级 diff）。⚠️ 服别不能混：APK/模拟器 = 正式服，
PC 客户端可能是体验服 ⇒ 名字/fid 可能不同。

```text
源包(只读) → 索引(10_索引) → 定位(names/locate) → 还原树(41_还原树) → 页面(04_站点)
```

## 3. 最重要的认知：两类条目

```text
【有名条目】fid = murmur3_x86_32(路径)，双 seed（高 0x77777777 / 低 0x66666666）
            ⇒ 算哈希 ⇒ 直接命中容器行 ⇒ 按名字精确定位
【无名条目】fid = 引擎内部 id（不是路径哈希）
            ⇒ 只能靠：① 邻接（同资源块连排）② .c159/.mtg 槽位语义 ③ 通道统计
```

### 无名贴图的身份判定（纯数学，禁止用肉眼）

| 特征 | 判定 |
|---|---|
| `R≈G≈128` 且 `B>200` | 法线图（标准） |
| `B` 通道 `std<1.5` 且 `B>200` | 法线图（细节） |
| ≥2 通道 `std<1.5` | 单通道数据图（蒙版/发光） |
| `R` 恒 `255` | 参数图 ParamMap |
| `R/G` 相关 `>0.8` 且饱和 `>40` | **基色图** |
| `R/G` 相关 `>0.8` 且饱和 `≤40` | 表面图/灰度图 |

## 4. 验收纪律（违反必返工）

```text
★ 0 命中 ⇒ 先怀疑代码（函数用错 / 偏移错 / 路径写法错），再怀疑数据
★ 哈希自证 ⇒ 拿【已知命名文件】算 fid，必须命中；不中 = 方法错
★ 完整 8 字节 ⇒ 4 字节命中在 ~90MB 高熵数据里可能只是巧合
★ 引用逐字读 ⇒ 一个字符不同 ⇒ fid 全变 ⇒ 必然 0 命中
★ 不靠行号推测 ⇒ 先用哈希锚定，再看邻居
★ 修复带契约测试 ⇒ 改完必须验无回归
```

## 5. Agent 最常踩的 8 个坑

| # | 现象 | 真因 | 解法 |
|---|---|---|---|
| 1 | `ModuleNotFoundError: toolkit_core` | 没设 PYTHONPATH | 见 §1 |
| 2 | 页面"改了没生效" | ① web 服务静默死 ② 资源 404 ③ 报错被吞 | 先探活 ⇒ 看网络 ⇒ 读 `window.__dbg` |
| 3 | `expected_single_block_got_56` | 把 `parse_gpk` 用在 gres 族 | 用 `parse_gpk_gres` |
| 4 | `'function' object is not iterable` | `parse_gpk` 返回的 `rows` 是**函数** | `rows_fn()` |
| 5 | `载荷里找不到 'x{'` | 传入的 payload 不对（不是表的问题） | 直接按 `x{+u32(len)` 切 |
| 6 | 引用查不到 | 引用方 `.c159`/`.mtg` 里的路径 ≠ 容器内路径 | 用**邻接 + 槽位语义**，别猜写法 |
| 7 | 改了代码没反应 | 工具放 `90_临时/` 被清 / 服务是孤儿进程 | 工具放项目里；服务用托管方式起 |
| 8 | 大文件推送被 GitHub 拒 | >100 MB 单文件 | 写进 `.gitignore` 再 `git rm --cached` |

## 6. 硬规则（不可违反）

| 规则 | 原因 |
|---|---|
| **源包只读** | 改原始客户端有封号风险；一切先 `cp` 副本 |
| **不改游戏客户端文件** | 同上 |
| **禁止动态内存 dump / 调试器 attach** | 反作弊红线 |
| **服别不能混** | PC 客户端与 APK/模拟器**可能不是同一服务器** ⇒ 资源/名字/fid 都可能不同；结论必须标服别 |
| **不为省事编数据** | 信息不足就如实说"未命中"，标注 `[inferred]` / `[missing]` |
| **页面文案唯一来源** | `00_治理/台账/`（不是代码注释） |

## 7. 典型任务怎么接

### A. "帮我找某张资源"

```bash
toolkit_cli.py names lookup '<游戏内路径>'          # 先按名字
# 未命中 ⇒ 从引用文件入手
python 01_工具/工具库/02_图文音频渲染/皮肤链与渲染/resolve_asset.py \
  --ref '<.mtg或.c159>' --container '<容器>'
# 仍未命中 ⇒ 无名条目 ⇒ 邻接 + resolve_asset.py --semantic
```

### B. "这个皮肤/资源要完全复原"

```text
① 定位真资产（四步法）
② 读材质槽位（.c159 → pbr_*.fx 反汇编 mov 序列）
③ 读配置（天气 / 相机 / 光照 / cube）
④ 接进页面 ⇒ 用 __dbg / __realTex 运行时读数验收
```

### C. "热更里新增了什么"

```bash
toolkit_cli.py delta
toolkit_cli.py hotfix apply          # dry-run
toolkit_cli.py loose scan --out out/ && toolkit_cli.py loose match --dir out/
```
