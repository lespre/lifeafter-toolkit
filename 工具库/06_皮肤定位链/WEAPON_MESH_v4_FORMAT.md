# NeoX 武器皮肤 .mesh 格式（v4）— 已破译

> 2026-09-13 破解（实证文件：`E:\la拆包项目\03拆包产物\weapon\003995.mesh` 等 5 个 LOD；通用性已验证：LOD1–4 + 预览版全部 0% 异常）
> 渲染器：`06_皮肤定位链/render_neox_mesh.py`（软件光栅，含量化反解/光照/泛光）

## 文件结构（字节级）

```
0x00  magic        u32 = 34 80 c8 bb
0x04  version      u16 = 4
0x06  const        u32 = 5
0x0A  data_size    u32 = 文件长度 - 16
0x0E  submesh 表   每项 10 字节 ×3：
        vc u32, fc u32, u16(=1: uv_layers=1, color=0)
0x2C  u16 终止符   = 1
0x2E  totals      tv u32（顶点总数）, tf u32（面数总数）
0x36  bbox        6×f32 = min角(x,y,z) + max角  ← 全局量化基准
0x4E  pos 流      tv×3 × int16（u16 量化: v=raw/65536, p = min + v*(max-min)）
       nrm 流      tv×3 × int16（方向可用；长度≈0.87，用前归一化；渲染用几何法线更稳）
       pad         u16 = 0     ← 【陷阱】面流从 nrm 结束 +2 字节处开始！
       idx 流      tf×3 × u16（三角形表）
       uv  流      tv×2 × float16
       trailer     16 字节（最后 = 01 00 0e 00 ... 计数类字段）
```

## 关键陷阱（踩过的坑）

1. **面流 +2 字节偏移**：`idx` 不是紧跟 `nrm`，中间有 u16 pad。
   若按 +0 读：约 45% 面变成 `(i,i,j)` 型"退化面"（其实全是有效面被错位读）。
   **判据：+2 读取后退化面 = 0%、边长 max≈1.1（+0 时 max≈10.5）。**
2. **反量化是"逐子网格"的**：三个子网格各自用自己那对 bbox（在 `.c159` 材质/描述文件里有精确值 + 网格头 float 有全局 bbox）。全用全局 bbox 会让子网格 1/2 轻微错位。
3. **`(i,i,j)` 形态不是数据损坏**——绝大多数是错位读取的伪影；一旦 +2 对齐就消失。
4. int16 量化读 unsigned（`raw.view(u16)`）优于 signed（实测边缘平滑度显著更好）。
5. 邻居条目会**跨皮肤混排**（如 003990 是隔壁 028 的材质）：归属只认条目内字符串 / 集群位置，勿按 ±1 相邻硬判。

## 资产集群形态（每皮肤）

```
[材质c159] [LOD1 mesh][LOD1 材质][LOD1 子网格描述] [LOD2..4 同构] [预览描述][预览mesh(常=LOD1重复)][预览材质]
贴图 dds 成组放在集群之后（3–5 张：a/m/n/b_m + 变体）
```

## 渲染管线

1. parse_mesh → P（float 坐标）/ uv / idx（+2 修正后）
2. 丢弃零面积面（安全线）；几何法线做平滑法线
3. 相机：正交 + 屏幕 2D roll（锚点同款 = roll 235°、eye=(1,0,0)）
4. 光照：headlight + 环境；金材质用 dds `001a` 基础色贴图
5. 泛光：亮部阈值 → 高斯模糊 → 加性合成（bloom=0.55）
6. 输出 PNG（1200×1560）

## 贴图角色与重建管线（skin_2003_029 极光剑 实证）

- **4011** = 基础色（金）：剑身/柄主色。其上的红橙色"碎晶"块为源贴图内容；宝石红色由**材质参数**（`u_crystal_color`/`u_subsurface_color`/`u_refraction_color`，见 `C159_PARAM_PAIRING.md`）驱动，**禁止人工重绘贴图**。
- **4009** = 银蓝系贴图：护手/银件近似来源（渲染时去蓝 75% + 提亮 ≈ 银白）。
- **4012** = 可用法线贴图（切线空间、绿通道正相、nrm_str≈1.1，浮雕感）。
- **4010** = 噪点法线，勿整体直用。
- **4013** = **材质遮罩**：唯一变化通道 = B；分布 = 材质岛内渐变 + 边缘带（非点状发光）⇒ 语义判定 **光滑度/光泽度(smoothness/gloss) 遮罩**，非发光层；禁止整图 RGB 当 Emissive 使用。（旧"发光层"标注已废止）
- 全部 BC7（DXGI 98）。
- 渲染管线 = 软件光栅：逐子网格贴图 + 法线扰动 + 冷色轮廓描边 + 泛光。金属全反射/宝石折射属引擎 shader 级，软件近似。
- 特效（火焰/闪电）= 粒子系统（`fx_skin_2003_029_idle_02.sfx`），不在网格里，属独立工程。
