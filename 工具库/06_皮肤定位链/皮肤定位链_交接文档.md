## 一、文件格式解析

### 1.1 script.py314.lc.npk（Python脚本包）

**文件位置**：`E:\mrzh\Documents\script.py314.lc.npk`

**格式结构**：
- 头部：32字节，AES-ECB加密
- 条目表：48字节/条目，包含file_id、offset、packed_size、declared_size、flag
- 数据区：LZ4/Zstd压缩

**AES密钥**：`60 63 08 D8 A3 2C 78 20 13 D2 6C 2F 22 6F 68 6D`

**解包后产物**：25,372个.bin文件，位于`E:\提取成果\配置数据\_script_raw\_raw\`

### 1.2 单个.py配置文件格式（关键突破）

**文件结构**：
```
偏移0-50:   文件头（51字节）
偏移51:      累积长度表开始（4字节小端整数，递增）
偏移N:       字符串数据区（累积长度表结束后）
```

**累积长度表解析**：
- 从偏移51开始，每个条目4字节，小端格式
- 值为递增的累积长度（如11, 21, 28, 42, 54...）
- 每个字符串的实际长度 = 当前累积长度 - 前一个累积长度
- 字符串数据起始位置 = 51 + 累积长度表条目数 × 4

**示例（000004.bin）**：
```
累积长度表: 11, 21, 28, 42, 54, 75, 94, 114, 123, 137, 156, 166, 181, 206, 218, 265, 312, 371, 430, 503, 576, 629, 682, 697, 709
条目数: 25
字符串数据起始: 51 + 25×4 = 151
```

**解析脚本**：`E:\提取成果\明日拆包\工具库\06_皮肤定位链\parse_all_py_config.py`

## 七、注意事项

1. **文件格式**：单个.py配置文件的累积长度表从偏移51开始，4字节小端，这是关键突破点
2. **编码问题**：中文字符串可能需要倒序或特殊编码处理
3. **服务器差异**：经典服、简单生存服、会员服共享底层资源，但实装内容不同
4. **体验服vs正式服**：体验服独有内容在.fpk（002-014、023-064）和部分.gpk中
5. **只读原则**：所有操作只读原始包，产物放在E盘其他目录
