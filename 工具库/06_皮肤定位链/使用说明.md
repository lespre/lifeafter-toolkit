## 核心算法

### 1. IDX索引格式（SKPW魔数）

```
头部: 32字节
  - 0-3: 魔数 "SKPW"
  - 4-31: 元数据

条目: 每个36字节，从偏移32开始
  - 0-15:  16字节hash（资源唯一标识）
  - 16-19: 保留
  - 20-23: WPK包索引（如3表示weapon3.wpk）
  - 24-27: 数据在WPK中的偏移
  - 28-31: Payload大小
  - 32-35: Header大小（固定48）+ 其他标志

最后4字节: 校验和
```

### 2. WPK按需包 + 1DPW加密

每个WPK文件包含多个1DPW加密条目：

```
1DPW条目结构:
  - 0-3:   魔数 "1DPW"
  - 4-47:  头部（48字节）
  - 48+:   Payload（AC/PC/XC前缀加密）

解密流程:
  1. AC/PC/XC前缀解密（AES-ECB + XOR流 + 字节反转异或0x5A）
     - 派生key算法: derive_key(length, t)
     - tag: AC=0x4341, PC=0x4350, XC=0x4358
  2. ENON层剥离（如果存在）
  3. DTSZ/ZSTD解压（如果存在）
  4. 得到明文DDS/PNG/JPG
```

### 3. FHPK哈希表格式

```
头部: 16字节
  - 0-3:   魔数 "FHPK"
  - 4-7:   版本 (2)
  - 8-11:  条目数 (1572)
  - 12-15: 保留 (40)

条目: 变长
  - 0-15:  16字节hash
  - 16-23: 保留（8或16字节）
  - 24-25: 路径长度（2字节小端）
  - 26+:   路径字符串（UTF-8）
  - 之后:  元数据 + 填充对齐
```

## 技术细节

### AES KEY（GPK/FPK通用）
```
60 63 08 D8 A3 2C 78 20 13 D2 6C 2F 22 6F 68 6D
```
算法：AES-ECB，头部按16字节倍数补齐后整体解密

### 1DPW派生Key算法
```python
def derive_key(length: int, t: int) -> bytes:
    v10 = (t + (length & 0xffffffff)) & 0xff
    v28 = 0x7C2E6B6A00000000 | (((length & 0xffffffff) << 8) & 0xffff0000) | (v10 << 8) | (length % 0xfd)
    v29 = 0x5C74656E00003630 | (((v10 ^ 0x33) << 16) & 0xffffffff00ffffff) | ((v10 | 0x2e) << 24)
    return struct.pack('<QQ', v28 & 0xffffffffffffffff, v29 & 0xffffffffffffffff)
```
