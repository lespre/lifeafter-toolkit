## 六面编码警告（**不要跳过**）

`faces[]` 指向 **`rgbm/` 子目录**，不是交付的人眼 sRGB 六面。

查看器源 IBL 分支按 **asm 542-544** 解码：`q_L = pow(rgb * a * 16.0, 2.0)`，
且 cube 纹理显式 `t.colorSpace = T.NoColorSpace`（L1799）⇒ shader 拿到**存储字节原值**，
**alpha 通道是 RGBM 乘子**（源六面实测 alpha mean = 0.015 / 0.028）。

* 喂**无 alpha** 的 sRGB 六面 ⇒ `a=1.0` ⇒ 亮约 4400×：
  实测 **p50 0.9679 / p95 0.9992 / >0.85 76.58%**，**比游戏参考目标还高** —— 这是**纯编码假象**，
  不是环境更亮。**任何人不得拿这个数去声称「达到/超过游戏目标」。**
* `faces_srgb[]` 仅供人眼看图，**不要**喂查看器（清册里已单列该字段）。
