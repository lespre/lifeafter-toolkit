# 02_资料 — 目录骨架（纯展示，不含内容）

> **本目录在仓库里只保留骨架，不含任何数据。**
> 里面所有东西都是**源材料**（游戏源包 / 热更包 / 交付件），
> 体积可达几十 GB，且属于第三方内容，因此不入库。

---

## 结构

```text
02_资料/
├── 源包/                          原始源材料（只读；一律先复制再动）
│   ├── apk_<日期>/                 APK 解出的资源（★ 正式服，与 PC 测试服不同源！）
│   ├── emu_<日期>/                 模拟器拉取（★ 正式服）
│   ├── players2021_layers/         分层资源
│   ├── post_update_<时间戳>*/      热更后快照（按时间戳分）
│   │   └── raw/                    热更容器（.idx + *.wpk 等打包件）
│   ├── pre_update_<时间戳>/        热更前快照（用于 diff）
│   └── 热更历史容器_*/             历史热更容器归档
│
└── 交付/                          对外交付成品
    ├── 交付_<皮肤ID>_源驱动_<日期>/
    ├── 交接_<日期>/
    ├── <活动名>_3D浏览/
    ├── 武器纹理分析/
    ├── 皮肤库web/
    └── ...
```

---

## 铁律

| 规则 | 说明 |
|---|---|
| **源包一律只读** | 任何操作先 `cp` 到工作目录，改副本 |
| **先记哈希** | 复制后必须记 `sha256` / `md5`，便于事后自证 |
| **服别不能混** | PC 客户端（如 `E:\mrzh`）与 APK / 模拟器**可能不是同一服务器** ⇒ 资源 / 名字 / fid 都可能不同，结论必须标服别 |
| **不入库** | 体积大 + 第三方内容 ⇒ 只保留骨架 |

