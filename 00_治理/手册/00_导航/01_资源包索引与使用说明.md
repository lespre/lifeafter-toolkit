### .nxs 配置表通用解码方法（可复用）

**核心工具**：`工具库/05_BinDict解码器/nxs_config_decoder.py`

**解码原理**：
1. 直接UTF-8解码提取中文字符串（大型配置表适用）
2. 关键词搜索定位（在原始字节中搜索）
3. 上下文提取（前后指定大小）
4. 正则表达式提取结构化数据

**使用方法**：
```bash
# 基本使用
python nxs_config_decoder.py <nxs文件路径>

# 带关键词搜索
python nxs_config_decoder.py <nxs文件路径> 武器皮肤 极光剑 战神烈火剑
```

**Python API**：
```python
from nxs_config_decoder import NxsConfigDecoder

decoder = NxsConfigDecoder('1B249D5C9984E1B4.nxs')
weapon_skins = decoder.extract_weapon_skins()  # 提取武器皮肤列表
fashion_items = decoder.extract_fashion_items()  # 提取时装列表
results = decoder.search_keyword('极光剑', context_size=200)  # 关键词搜索
```
