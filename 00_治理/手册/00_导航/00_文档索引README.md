## 三、当前结论的取用规则

1. **奖池**：只认 `活动配置 → lottery_id → reward_pool D6 行 → slot → jump → item_id` 的完整链；不认 `entry 2662` 文字池、主题词、页面展示列表。
2. **武器皮肤名**：优先 `common_item_data.item_id == skin_id`；特效名不是皮肤名。
3. **未上线**：必须满足“热更新表级 key 新增 + 历史更新表未出现 + 服务器启用状态不冲突”。
4. **图片/模型**：逻辑路径或同包出现不等于实体资源已闭环；禁止尺寸、颜色、相邻偏移、视觉相似绑定。
5. **版本差异**：正式服只用于结构对照，不可拿正式服资源作为体验服内容证据。
