## 3. 结论（可证伪）

**① 「源声明组」明显更差 —— 如实记录，不美化。**
换成 c159 声明的 indoor 后：**p95 113.2 → 46.8（−66.4）**、框内 R 均值 31.07 → 15.32（**−51%**）、**银%（L>90 的中性高光）3.22% → 0.00%**、金% 1.50 → 0.68、p50 35.8 → 32.7（**−3.1**）。两轮逐像素一致 ⇒ 不是噪声。若有人主张"indoor 与 gdansk 外观相当"，只需出示其 A/B p95 差 <5 或银% 不为 0 即可证伪本结论。

**② 差的机制是 cube 本身（可量化）：源公式把环境项平方，indoor 又暗又有一个纯黑面。**
源注入公式为 `_L = (rgb * a * 16)^2`（viewer SRC_ENV_GLSL / asm 542-544）。按六面逐像素计算该项均值：**indoor = 0.0154，gdansk = 0.7540 ⇒ 比值 0.020（≈1/50）**；其中 indoor 第 4 面恒 0。若该比值被证伪（例如两 cube 的 `(rgb·a·16)²` 均值同量级），本条不成立。旁证：A 组 `ibl_faces=6`、六面请求全 200（不是加载失败），故变暗来自数据而不是链路。

**③ 与 task-15 的 `_a/_b_m` 结论方向相反，不能一句"越忠于源越好"概括。**
`_a/_b_m`：Δp50≈0、Δp95 +5.4（高光抬升）⇒ 换回源声明**改善**；本次 IBL：Δp50 −3.1、Δp95 −66.4（整体变暗、高光崩塌）⇒ 换回源声明**明显劣化**。两条都可复现，故"源声明一定更好/更差"两种笼统说法都被证伪。
