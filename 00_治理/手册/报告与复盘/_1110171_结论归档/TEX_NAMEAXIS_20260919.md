## 4. 决定性发现：`idx_key` = 内容 `md5`（回答你的“顺带”问题）

- 逐条实测（primary 1,031 条，全部重新解包 + 哈希）：
  - `key == md5(DDS payload)`：**1,031 / 1,031** ✔
  - `key == sha1[:16]` / `sha256[:16]` / `sha256[-16:]` / `md5` 的其他排列：**0**
  - `key[:8].hex == md5[:16]`（即键的前 8 字节就是 wiki 用的 8-hex 标签）：**1,031 / 1,031** ✔
- 独立互证：磁盘上已提取的 1110171 池 DDS `_sfx_029\texture_pool\7240b8319d081a0f.dds`（87,556 B，256²，`md5=3c21981b4615e1ddaa3cb6fa5fa15c06`）与 **idx 第 874 条**键 `3c21981b4615e1ddaa3cb6fa5fa15c06` **同源**；`render_1003_010\_sfx_010\texture_pool\` 下同名文件字节相同。
