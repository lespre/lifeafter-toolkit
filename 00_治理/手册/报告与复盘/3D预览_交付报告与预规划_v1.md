### 3. 查看器（`assets/weapon_skin_viewer.js` → v1.2.0）本轮修的 4 个真实缺陷

| # | 缺陷 | 根因（实测） | 修复 | 验收数据 |
|---|---|---|---|---|
| 1 | **模型偏右下 + 右/下被裁** | CSS **漏了 canvas 尺寸规则** → 浏览器按 canvas 属性尺寸(=舞台×DPR)布局 → DPR>1 溢出被裁 | 补 `.wv-canvas canvas{position:absolute;inset:0;width:100%;height:100%;display:block}` | dpr 1/1.5/2 下 `canvas 布局 == 舞台`；150% 截图居中无裁切 |
| 2 | **取景不居中** | 原用"包围盒中心+固定半径倍数"，**透视下 8 角投影框并不以中心对称** | 改为按投影框迭代收敛（跨度→0.84 + 投影重心回正，3 轮 + 收尾再拟合） | `projCenter=(0.500,0.499)`、`clipped=false`（dpr 1/1.5/2 一致） |
| 3 | **转到极点卡死** | OrbitControls 锁定上方向，竖拖到极点即锁死（实测同向拖第 2 次起轮廓差异 **0.000**） | 换 **TrackballControls**（无上方向约束，横竖 360° 无限） | 同向竖拖 5 次轮廓差异 **0.958/0.954/0.906/0.820**（均"继续转"） |
| 4 | 拖完点"复位"被惯性带偏 | OrbitControls 阻尼余速（`_sphericalDelta`）持续生效 | 取景/复位前清余速 | 复位后极角精确回预设 1.3456 |

附带：本地服务对静态资源加 `Cache-Control: no-store`（此前 CSS 版本号 `?v=viewer1` 从未变过 → 只改 JS 版本用户永远拿不到新文件）；给前端加了可见版本标记与 QA 只读访问器 `WikiWeaponViewer.__state()`。

## 三、预规划（请 GPT 审核）

### P1 · 对齐口径定案（0.5 天，最高优先）
1. 用**修好的**渲染器重出两个皮肤的海报（统一 `eye=(-1,0,0)`、`roll=90`、`2260×1150`）；
2. 在**同一口径**下确定 `states[].rotation`：候选 `[0,0,0] / [180,0,0] / [0,0,180]`，判据 = **查看器截图与海报的直接目视比对**（数值 IoU 已证明受辉光层干扰，不作主判据）；
3. 结论写入 skill（`lifeafter-wiki-boards`）+ provenance `rotation_note`。
**验收**：用户目视确认"打开即与卡片同姿态"。**风险**：若两皮肤口径不同，需按皮肤存 rotation（已支持）。

### P2 · SFX 上屏（010 优先，029 复用）
1. 复用 010 已解码的 `.sfx`（GBK XML FxGroup，20 节点）→ 出 `t=0/0.5/1.0` 三帧 → 短循环；
2. 补 `registerEffectsAdapter`（查看器唯一缺口）→ 无/有 SFX 一键切换；
3. **贴图映射（U3）不解决就不上"精确贴图"**：先用源参数驱动 + 明确标注候选/未定；
4. 029：先按 c159 找绑定文件（010 的方法：`c159_pair` + gpk 内容实证扫描）。
**验收**：三帧 + 循环可看；未支持节点显式 `unsupported`。**风险**：U3 若长期不破，SFX 只能到"结构级"。

### P3 · 上色/材质（029 走 `pbr_default` 独立路径）
1. 029 刀身是 `pbr_default`（非 `pbr_weapon`：6 个 SV_Target、`o0=Tex0.yzw`），**不得套用 pbr_weapon 通道语义**；
2. 按外审 v7.1 的因果实验顺序分层输出（Canonical Tex0 → +材质色/顶点色 → +直接光 → +IBL → +emissive → +bloom），**每一步记录新增输入与公式**，金色在哪一步出现才定性；
3. 红线不变：**不按参考图改色、不人工 tint、坐标选面、后处理补色**；缺真实 cube 时 IBL 之后不定案。
**验收**：分层图 + 每层 provenance；查不到就写 unresolved。

### P4 · 通用化（收口）
把"一个皮肤 → wiki 3D"封装为单命令流水线（`build_wiki_3d.py <mesh> <texmap> <skin_id> --submap ...`）：导出 GLB → 渲海报 → 写 viewer/provenance/effects → 投放 → 重建索引 → 自动验收（`projCenter/clipped/字节一致`）。目标是任一皮肤 ≤3 分钟进 wiki。
