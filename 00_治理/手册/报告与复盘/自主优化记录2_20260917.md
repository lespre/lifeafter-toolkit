## 一、`t_surfacemap` 语义 —— **查到硬证据，结论是「不该接」**

### 证据链

1. `_known_loop/slot_rules_v1.json`：`"001s_m\\.tga$" → "t_surfacemap"` ——
   **该槽位来自「文件名规则」，不是着色器证据**。
2. `_known_loop/dxbc_rdef_strings.json` / `dxbc_var_scan2.json` / `dxbc_local_global_vars.json`：
   **着色器变量表里没有 `t_surfacemap`**（只有 `u_*` 与 `t_skin_bone_animation` / `t_vlm_*`）。
3. **决定性**：项目自身的 DXBC 实验渲染器 `render_experimental_dxbc_pbr.py` 的 `formula_source` 表写着：

   ```
   "surfacemap": "武器端 SV_Target3.y = t_surfacemap.x（规范 RGBA 的 R 通道）"
   · surfacemap.x / ParamMap.w → 诊断层（语义未赋名）
   ```

   即 `t_surfacemap.x` 写进 **延迟管线 GBuffer 的 `SV_Target3.y`** —— 属材质数据通道，
   **并非**可直接乘到 albedo / specular / AO 的常规贴图；项目自己已标「**语义未赋名**」。

### 处置

**不接入**（接入即按槽位名猜测）。改为把「为何未消费」连同上述证据写进 `neox_material.json`：

```json
"t_surfacemap": { ..., "viewer_usage": "NOT_CONSUMEd",
  "unresolved_reason": "…SV_Target3.y = t_surfacemap.x…语义未赋名…需先从 DXBC 定证消费方 pass 与位包布局…" }
```

→ 现在它看起来不再是"漏了"，而是"证据不足、已登记"。**2 个槽位已标注。**

## 二、参考图的辉光从哪来 —— 已排除自发光参数

对 `_known_loop/c159_params_001265.json` 做全参数枚举（本皮肤 5 个晶体 prim）：

```
u_base_color, u_caustic_brightness, u_caustic_depth, u_caustic_tilling,
u_crystal_color, u_crystal_metallic, u_crystal_specular,
u_detail_intensity/u_detail_tilling（prim6 另有 u_detail_offset_x/y + u_crystal_roughness）,
u_refraction_brightness, u_refraction_color, u_refraction_contrast, u_refraction_rotation,
u_subsurface_color
```

**关键词检索结果：`emissive` 无 · `glow` 无 · `fresnel` 无。**
→ **参考图那种发光感不是自发光参数驱动的。**

**而上述参数一个都没进渲染**，原因很清楚 —— 它们各自依赖的贴图都缺失：

| 源参数组 | 依赖贴图 | 状态 |
|---|---|---|
| `u_refraction_*`（4 个） | `t_refraction_tex` | **缺失**（候选 `gpk_1230` 未升级） |
| `u_caustic_*`（3 个） | `t_caustic_tex` | **缺失**（候选 `gpk_1276` 未升级） |
| `u_detail_*` | `DetailMap` | **缺失**（候选 `gpk_1229` 未升级） |
| `u_subsurface_color` | —（纯色） | 可用，但源公式未复现 → 不猜 |
| `u_crystal_specular` | —（标量） | 同上 |

**结论：辉光缺口的根因 = 3 张候选贴图未升级 + 对应层未实现**，而不是"忘记加自发光"。

## 五、尝试：恢复链生效时的 ACES tone mapping（**无可测效果**）

生产路径的「清除旧污染」块会把 `toneMapping → NoToneMapping`、`bloom.strength → 0`。
但该块是为**无光照预览模式**写的，而渲染器创建时本是 `ACESFilmicToneMapping`。

**改动**：仅当 `state.neoxReport.applied > 0`（链生效）时**不强制** NoToneMapping，保留渲染器自身 ACES。

**结果：weapon-only 指标逐字节不变**（gold 22.32 / p50 0.115 / p95 0.444）。

→ 说明该block 不是暗的主因（要么本就已 ACES，要么 composer 接管了输出转换）。
**改动无害且语义更正确，保留**，但如实标注「无可测效果」，不冒充成果。
