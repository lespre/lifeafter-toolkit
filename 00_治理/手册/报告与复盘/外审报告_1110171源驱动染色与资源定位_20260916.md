### 3.5 当前实现的源驱动公式

```
pbr_weapon  ：BaseColor = Tex0.rgb；Metalness = ParamMap.G；Roughness = ParamMap.R
pbr_crystal ：m = saturate(Tex0.r)
              A = lerp(T, T × u_crystal_color, m)
              B = lerp(u_base_color, T × u_crystal_color, d)，d = m × DetailMap.a
              C = lerp(A, B, m)
              Metallic = u_crystal_metallic（逐材质）

其中 Tex0(b_m) 仅按 .r 读取作掩码（G/B/A 不参与）
```

## 六、当前对不上的原因（机制，已定位）

链驱动下：晶体呈**暗蓝紫**（lum 0.184）、武器区**过曝白**（lum 0.995），而参考是**明亮暖金 + 低色度银白**。机制：

1. 源材质 `metalness = 1`（`u_crystal_metallic` = 1.0；weapon 的 `ParamMap.G`）→ **外观 ≈ 环境反射 × 本色**。
2. 源环境（`car_studio01.cube`）缺失，当前用中性棚光替代（已如实标记，非源级）→ 金属失去方向性能量：武器反射成白、晶体无明显环境注入。
3. 数学反证：`u_base_color`、`u_crystal_color`、`t_basecolor` 三者皆为冷色，权重 0–1 的三次 lerp **不可能生成金色**。
4. 因此参考中的金色**只能来自**：(a) `pbr_weapon` 的 `Tex0`（金色确实存在，UV 采样暖金 70.7%），或 (b) 源 IBL / 焦散 / 折射层的能量注入。
