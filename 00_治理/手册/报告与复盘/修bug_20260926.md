## A12 ★ viewer 硬编码 `src_tex/gpk_1229.png` 导致其他皮肤 404

### 现象
登记：`04_站点\web\viewer.js` 约 1540 行硬编码了 `src_tex/gpk_1229.png`；该文件只存在于 `assets/3d/weapon_skin/1110171/` 与 `1110171_cand` ⇒ 其余 36 个皮肤每次载入都 404。

### 复现前的定位更正（先读文件再动手）
- `04_站点\web\viewer.js` **不存在**。全库 `viewer*.js` 只有 4 个，真身在
  **`04_站点\web\assets\weapon_skin_viewer.js`（6975 行）**（另一个是 `01_工具/工具库/02_图文音频渲染/3D预览器/poster/assets/weapon_skin_viewer.js`，md5 与前者**逐字节相同**，是镜像）。

  ```js
  const legacyDetailPath='src_tex/gpk_1229.png';
  const legacyDetailTex=(state.__useLegacyDetail===true)?tex(legacyDetailPath,false):null;
  ```
  且 `tex()`（L1511）直接 `new TextureLoader().load(base+f)`，**不校验存在性、也不校验是否 manifest 声明**。
- 目录盘点（实测）：`assets/3d/weapon_skin/` 共 115 个子目录，其中 **39 个含 `viewer.json`**；
  `src_tex/gpk_1229.png` 只出现在 `1110171` 与 `_cand_1110171` ⇒ **其余 37 个目录无此文件**。

### 复现（无头 Chrome + Network 域实测）

- `window.__legacyDetail()`（L~6090）：输出 `legacy_hardcoded_path:'REMOVED (2026-09-26 A12)'`、`legacy_source:'manifest.DetailMap.file'`、`legacy_path`；

- 镜像同步：`01_工具/工具库/02_图文音频渲染/3D预览器/poster/assets/weapon_skin_viewer.js`（改前 md5 两边相同 ⇒ 改后同步保持相同）。
