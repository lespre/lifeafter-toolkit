## S3. 解码（"拿到字节"）

| 类型 | 规则 |
|---|---|
| **c159** | AES-ECB 头；entries `u32@20`，`64 + 32B/行`，数据在 `o+36`；flag `0`(AES-deflate) / `2`(lz4) / `12`(zstd)；头变体 magic `RPGF/OPGF/ZPGF` |
| **DDS / BC7** | `texture2ddecoder.decode_bc7`，**BGRA→RGBA 重排**，**必须保留 alpha**（本项目出过"提取丢 alpha"事故） |
| **cube DDS** | 六面；**排布是 mip-major**（拿 face-major 解会得 40.05 的荒谬值，本项目出过一次并自证修正） |
| **`.mesh`** | magic `34 80 c8 bb`，`u16@4=4`、`u16@6=0x0500`、`u16@8` 低=骨骼标志/高=骨骼数 |
| **`.gim`** | **是模型文档（c159 对象图 `C159410D`），不是几何**；几何/骨骼在**同 stem 的 `.mesh`** |
| **`.tga`** | 原样保留，**不转码、不改名**（环贴图仍未定位，禁止生成替代） |

**自检习惯**：解出来先跑一次 hexdump/字符串表，确认 magic 与期望类型一致，再往下走。

⛔ **必须按 shader 家族分表（已更正）—— 不同家族不能混用同一套派生规则：**

| 家族 | 源公式（已独立验证的范围） | three 读法 | 派生文件 |
|---|---|---|---|
| **`pbr_weapon`** | `metal = sat(ParamMap.G)` · `rough = clamp(ParamMap.R, 0.02, 1)` | `metalnessMap.B` / `roughnessMap.G` | `param_repack_<fam>.png`：`B ← src.G`、`G ← clamp(src.R,0.02,1)`（three 不读 G）、`R`/`A` 填常量 |

⛔ **"纯通道重排、零数值改动"是不准确的（已更正）**：实际生成器会执行 **`clamp(0.02, 1)`** 并**填充常量 R/A**。准确表述：

⛔ **`gen_param_repack.py` 只生成 `param_repack`，不生成 `rough_repack`**（与本文档旧表述不符，已更正）。因此：

## S8. 查看器接线（`assets\weapon_skin_viewer.js`，唯一写者制）

`applyNeoxManifest()` 的主流程与硬规则：

| 环节 | 规则 / 事实 |
|---|---|
| 材质 | `MeshStandardMaterial`；**颜色槽必须按 program family 显式声明，不许用通用 `\|\|` 回退**（见下） |
| ⛔ **必需槽（已更正）** | 旧写法 `colored = t_basecolor \|\| Tex0` 会把**缺失/错绑静默掩盖**，与 fail-closed 自相矛盾。正确做法：<br>① **每个已识别的 program family 单独声明 required slots**；<br>② **声明了 `t_basecolor` 的变体缺它 ⇒ 直接隐藏/失败**（不得回退到 Tex0）；<br>③ **只有经 RDEF/DXBC 证明"不消费 `t_basecolor`"的变体**，才允许只使用 `Tex0`；<br>④ `\|\|` 一类的通用回退**一律禁止**。（viewer 侧改动**待办**） |
| 逐族一致 | `famOf(Tex0/NormalMap/ParamMap/t_surfacemap)` 必须同族，否则记 `__famMismatch` |
| 源 IBL | 逐材质 `t_custom_ibl` → cube 六面 URL；**六面 URL 必须互异**，否则 `state.__cubeDirErr` + `return null`（不缓存坏 cube）+ env 模式降级为 `duplicate_face_urls_ibl` |
| `faces_glob` | 只替换 `{...}` 占位符；**写 `f*` 这种 shell 通配会六面坍缩成同一个 404 ⇒ 空 cube ⇒ 全黑** |
| 粗糙/金属 | `param_repack` / `rough_repack`（见 S5） |
