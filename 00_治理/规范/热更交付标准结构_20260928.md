# 热更拆包 · 标准交付结构（规范 v1）

日期：2026-09-28 ｜ 状态：**已实现并实测** ｜ 实现：`toolkit_core/hotfix_bundle.py` + `hotfix bundle` 命令

---

## 一、为什么要规范

此前 `hotfix all` 的产物只有两个：一个 3.8 MB 的 `hotfix_report.json`（机器读、人没法看）
和 `pkgs/`（原始包）。**定位与解包已经彻底（372/372），但交付形式没有章法** ——
分类靠人记、找东西靠翻 JSON、名字不明的产物没地方放。

对标了这几个项目的约定后定下本规范：

| 借鉴点 | 来源 |
|---|---|
| 一个根目录按类型分子目录 + 顶层 `manifest.json` 作主索引 | Intelli-verse-X `asset-pipeline-standard` |
| `inventory` 模式（按类型统计数量与体积） | EchoTools/evrFileTools |
| `--skip-unknown`：名字不明的**单独**处理 | eigeen/ree-pak-rs |
| `.manifest.txt` 缓存做**增量**（只写变化） | ValveResourceFormat / Source2Viewer |
| 「有些游戏把 namelist 放进包里」→ 从元数据反推名字 | PS2Sanctuary/Mandible |
| 先拿清单再精准拉，不盲目全下 | DepotDownloader 数据挖掘工作流 |

## 二、结构

```
<交付目录>/
  README.md                人读：本次热更干了什么、判据是什么、怎么复现
  manifest.json            ★ 唯一真相源：每条含 路径/容器/行号/大小/sha256/来源包/note
  inventory.json           ★ 类型统计（按扩展名 + 顶层目录的数量与体积）
  hotfix_report.json       六步流程报告（保留）
  pkgs/                    原始下发包（保留以便复现）

  ├─ 01_还原树/            ★ 按名字还原的目录树（幂等，硬链接）
  │      有名字 → 游戏内路径（如 ui/huancai_diancang_choujiang_zs.csb）
  │      无名   → _未命名/<容器stem>/<行号>.<ext>
  ├─ 02_文字表/            ★ 文字表单独汇总
  │      索引.json · 文案_去重.txt · 文案_按表.tsv · 分类.md
  ├─ 03_影音图文表/        ★ 影音图文单独汇总
  │      音频/ 视频/ 图片/ 特效定义/ 文本/
  ├─ 04_图集/              spine 图集（atlas / 本体 / sprite）
  ├─ 05_变更清单/          新增 / 移除 / 内容变更
  ├─ 06_脚本层/            脚本层（marshal 明文壳等）
  └─ 99_未归类/            ★ 取不到名字或格式不认的
         未归类清单.csv（container/row/name/ext/size/saved_as/sha256/note）
         <包名>_块<N>.<ext>（★ 内容字节也要留下，不能只记一行 CSV）
```

## 三、三条铁律

### 1. 定位判据 = **内容哈希**，不是尺寸

```
✓ overlay 帧的 SHA-256 对本地产物的 SHA-256
✗ 用「解码后字节数」—— 尺寸会撞（实测多个帧尺寸相同会落到同一行）
```

### 2. 分类判据 = **内容魔数**优先，扩展名兜底

无名块靠魔数认类，比扩展名可靠：

```
\x00\x00\x00 ftyp / ftyp → 视频
FSB5 / RIFF / OggS       → 音频
DDS  / \x89PNG / \xff\xd8\xff / GIF8 → 图片
<FxGroup                 → 特效定义
0x73 / 0xe3（marshal）    → 脚本层
```

**实测效果**：加上魔数分拣后，`03_影音图文表` 从 9 个文件 → **93 个**。

### 3. 不编造

- 取不到名字 → 进 `99_未归类`，**note 里写明原因**（不写「未解析」这种占位）
- **内容的字节必须留下**（落 `99_未归类/<包名>_块N.<ext>`），不能只登记一行 CSV
- `manifest.json` 是唯一真相源，各分类目录都从它派生

## 四、幂等

```
· 硬链接（同一分区时）：不占额外空间
· 目标存在即跳过（FileExistsError/权限错都吞掉）⇒ 可重复跑
· 内容索引增量：mtime 没变就不重算
   实测第二轮：待算 38,309 → 15,049（其余 293,019 命中缓存），326.9 行/秒
```

cd E:/la拆包项目
