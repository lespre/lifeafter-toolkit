## 三、这套链路解决的核心问题

```
「一次热更到底动了什么」—— 必须两个来源合起来才全：

① overlay 清单（客户端原生）→ 覆盖【两类变更】
     · 新增路径  ：内容落 gres\0000.gpk（增量包）
     · 内容变更  ：内容落该族自己的容器（scene_03 等）
        ★ pkg_N.pi 的 path 级 diff 抓不到这类（fid = murmur3(路径)，路径没变）
   实证：instance 两个包 361 块，100% 命中 scene_03，且 0 个属于「新增」

② pkg_N.pi diff（官方）→ 补【文件级粒度】
     新增 23,322 个 fid / 移除 3,879 个
     且能做到权威归属（H-3）：某 fid 属于哪个官方包 + 包内第几条
```
