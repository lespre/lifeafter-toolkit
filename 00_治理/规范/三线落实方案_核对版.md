## 一、总图

```
① 解码定位复原线            源包 → 事实（这条在哪、是哪条、是什么）
   ├ ①-0 索引地基           建库 / 校验 / 新鲜度 / 容器登记
   ├ ①-1 定位复原           路径→fid→行；名字↔条目；定位链
   └ ①-2 解析复原           表/纹理/音频载荷 → 行级事实

② 图文音频渲染线            事实 → 能看能听的东西
   ├ ②-1 3D                 装配帧 → 网格 → GLB
   ├ ②-2 贴图               DDS/立方体/立绘海报
   ├ ②-3 音频               bank → WAV
   └ ②-4 出图校色           非交付面 PNG / 色彩校验

③ 前端展示交互线            东西 → 人能点的页面
   ├ ③-1 页面与看板         wiki / board / 专题页
   ├ ③-2 服务与契约         services / api / wiki_server / 启动脚本
   └ ③-3 资产落地与投影     五件套落地 / build_boards / 发布门禁

━━━━━ D 横切带：数据契约（①③之间的唯一接口，不是线）
━━━━━ Q 横切带：质量·交付·治理（三条线都要过的闸门，不是线）
```

**为什么数据不独立成第四条线**：它的边界是**口径**（这行算不算事实、谁定口径、拿不到怎么标），不是**动作**。把它平级，会立刻出现「①说解出来了、②说按它渲染、③说按它展示，对不上时谁改口径」。
**先例警告**：`toolkit_core/lines.py` 里那个已经失败过的「两条线模型」，就是把 script 包和 NPC 表归到了同一柜子。
