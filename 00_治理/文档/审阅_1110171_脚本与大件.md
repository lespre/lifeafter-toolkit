判据不是文件名前缀，而是 **docstring 里是否在算"颜色/通道/贴图绑定的来源"**。共命中 **5 族 / 31 个脚本**。

### 4.1 `AB_*`（6 个）—— **贴图绑定 A/B 与"是不是同一张图"的判别**

| 脚本 | 核心方法（函数名 → 在算什么） |
|---|---|
| `AB_prep.py` | 只读：导出 7 皮肤**逐 prim 的槽位绑定** + `_a` 对应文件的存在性 + c159 工件清单 → `AB_bindings.json`（**A 组映射的输入**，`sha16(p)` 哈希） |
| `AB_table.py` | **三源差异表**：`c159 逐槽直证` × `当前绑定` × `A 组` ⇒ 逐槽列出"谁说了什么"，输出 `AB_table.md/json` |
| `AB_metrics.py` | 固定布局**武器区指标**：`lum(a)` 亮度、`bbox_of(proj,w,h)` 由投影矩阵算武器像素区、`metrics(arr,bb)` 出 p50/p95/受光%/金银紫% |
| `AB_texdiff.py` | **`_a.png` vs `_b_m.png` 像素级差异**：跨通道**等式扫描**（A.R≡B.G 之类）+ 逐通道统计 + alpha 分布 ⇒ 回答"是不是同一张图的不同打包" |
| `AB_texdiff2.py` | 深挖二者关系：`fit(x,y)` 线性拟合 / gamma 假设 / **通道置换矩阵** ⇒ 定量给出 `r²` 与最优置换 |
| `AB_run.py` | 见 §3.2（**fetch 拦截改 Tex0 的 A/B 引擎**） |

> **结论级产出（已被文档侧吸收，代码可弃但要留可复算能力）**：`_a` 与 `_b_m` **不是同一张图**（13 对同尺寸但相同像素 0.00%、平均 |ΔRGB| 51.9–137.4），
> **唯一真拷贝是 `1110177 029_b_m.A ≡ 029_a.R`（r²=0.9984）**；`_a.A` 是真实变量通道，`_b_m.A` 10/13 对恒 255。
> ⇒ **`AB_texdiff2.py` 的"通道置换矩阵 + 拟合"是可复用算法**，不要连带证据一起删。

### 4.2 `AB2_*`（5 个）—— **IBL 六面 cube 的源级判定**

| 脚本 | 核心方法 |
|---|---|
| `AB2_dds_layout.py` | `load/extract(b,w,h,mips,layout,face)/variants(raw)` ⇒ **判定六面是 face-major 还是 mip-major**，并与磁盘 PNG 做 **4 翻转 × 2 通道序的最优 1:1 指派**（这是"C10 立方体面错切"的定证工具） |
| `AB2_dds_verify.py` | `decode_cube(path)` 解 6 个 mip0 面 → `cmp(a,b)` **RGB-only 比对**（★ 注释："排除 alpha 干扰，单独报 alpha 统计"）⇒ 判定"黑面"是源资产特征还是导出产物 |
| `AB2_precheck.py` | `dds_info(p)` + 三路先决：① 两 DDS 结构 + 六面 PNG 齐全且互异 ② manifest 的 `t_custom_ibl`（含 `faces_glob`）③ **c159 直证逐条**（`t_basecolor` 声明、`1110145` logical_path 取块、`indoor.cube` 字节位次） |
| `AB2_metrics.py` | `lum(a)` + `metrics(arr,bb)`：p50/p95/受光%/金银紫% + **复现性 + 布局恒定**（同一读数在两次运行/两皮肤上必须一致） |
| `AB2_run.py` | 见 §3.3 |

> **可复用算法**：`AB2_dds_layout.py` 的"布局判别 + 指派搜索"和 `AB2_dds_verify.py` 的 `decode_cube + RGB-only cmp`

### 4.5 `shader_*`（5 个）—— **GLSL 编译级取证（修"着色器致命缺陷"的方法）**

### 4.7 `fidelity\Q1` / `Q4` + `FXFIX_hue_payloads` —— **颜色序与色相的两处定量判定**

- **`fidelity\Q1_color_order.py` / `Q1_color_order_v2.py`**（**上色最核心的两个脚本**）：

> **判定：可复用（判据级，上色首选保留）**。`Q1_color_order*.py` 与 `FXFIX_hue_payloads.py` 是"**不用看图就能判颜色**"的两个工具。
