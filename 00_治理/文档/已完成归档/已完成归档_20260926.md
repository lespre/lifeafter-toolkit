### 10.2 改法：唯一事实源 + 引用语法

新增 **`00_治理/台账/三线台账.md`** —— 三线十段「有什么/缺什么」的唯一事实源。
在此改字，页面下一次轮询（15 秒）就变，**不需要改任何代码**。

| 写法 | 含义 |
|---|---|
| `{键}` | 取实时数据。键来自 `gen_home.collect()` 字段，支持点号（如 `{backlog.open}`）|
| `#编号` | 取 `待修问题清单.md`：文本用其标题，状态用其勾选 |
| 其它文字 | **人工判断**（能力描述、口径说明），原样显示 |

`#编号` 两侧行为相反，这是刻意的：

```
写在【缺什么】：条目未闭环 → 显示；已闭环 → 自动移除
写在【有什么】：条目已闭环 → 显示；未闭环 → 自动移除
★ 且 miss 里引用的编号一旦闭环，会自动【迁移】到 has
  （否则「补上了什么」会没痕迹）
```

段状态 `st` 也改成自动派生（原先手写）：
```
缺项里有未闭环的 ★★★ 引用 → miss
只要还有缺项          → warn
一条缺项都没有        → ok
```
