## 一、wiki 子卡详情页大迭代

### （1）从「展开详情」改为「弹出大子卡」

单击卡片不再就地展开，而是弹出一个完整的大子卡。信息更全，长列表不再把版面撑开。

### （2）大子卡支持「对比功能」

点「钉住对比」后，这张卡自动置于屏幕右侧；此时在左侧再选中任意一张，即可**双子卡并列对比**。

对比态支持左右切换（← / →）、Esc 退出；对比中仍可继续筛选与搜索。

## 三、clone 兼容性优化

> 目标：**别人 clone 这个仓库，基于自己设备的拆包（我的同款拆包器）内容，可以构建出一样的 wiki。**

### （1）路径可移植化

444 个脚本里写死的本机绝对路径（`E:/la拆包项目`、`E:/mrzh`）全部清除，统一走 `web/tools/la_paths.py` 单一入口：

- 项目自身路径 → 从仓库根推导
- 设备运行期路径 → 走 `LA_CLIENT_ROOT` 环境变量
- 溯源字面量 → **保持字面量**（破坏它就破坏字节级可复现）

路径可移植率：**13.3% → 100%**。

### （2）冷克隆不再起不来

`wiki_server.py` 顶层硬依赖 `cryptography`，缺库时整站（含纯静态页）崩溃。现改为可选依赖 —— 缺库只跳过实时源，不影响浏览。

### （3）五关验收脚本

```bash
python 02_wiki/web/tools/checks/clone_repro_check.py
```

一次跑完：

| 关卡 | 内容 |
|---|---|
| G1 | 冷克隆完整性 |
| G2 | 无依赖起站 |
| G3 | 路径可移植性 |
| G4 | 条目指纹可复现 |
| G5 | 发布门禁 |

G4 用**条目指纹**逐条比对 —— 你在自己设备重建后跑一遍，就知道是否一致。

### （4）零依赖也能跑

`web/tools/mini_yaml.py` 是无 PyYAML 时的兜底 YAML 解析器（与 PyYAML 在 52 个规则文件上**逐字段等价，0 差异**）。系统 python 装个依赖都不用，也能跑编排器体检。

### （5）重建流水线闭环

```bash
python 02_wiki/web/tools/build/build_pipeline.py --check          # 体检
python 02_wiki/web/tools/build/build_pipeline.py --board X --apply # 重建单板
```

串联：灰度快照 → 主产出 → 后处理 → 溯源契约修复 → 发布门禁 → 条目级 diff → 更新日志草稿。

默认 dry-run，`--apply` 才落盘。每一步的执行顺序来自 `rules/pipeline_graph.yml`（**唯一执行来源**，每条都写明「为何排此位」）；未声明顺序的板会列为待补，**不臆造**。

### （6）幂等性修复

板级重建脚本同输入重跑，产物必须字节不变。

实测发现 `meta.notes` 无条件拼接会让噪声无界增长（累积到 31 段），且**幂等性永不成立**（哈希必变 ⇒ 每次 diff 都报「修改」⇒ 灰度回滚判据失效）。已改为幂等追加。

### （7）仓库瘦身

补齐 `.gitignore`，把本机一次性产物全部排除在外 —— 克隆者不用下载这些垃圾：

- 1.7G 审计候选大表（可由客户端产物重建）
- 958M 图片缓存
- 24M 改写器自动备份
- 4.2M 音频去重垃圾
- 根目录临时脚本、本地设计草稿、运行期状态报告

## 四、发布门禁首次全绿

三处根因，逐个查证后修掉（**不伪造任何溯源事实**）：

1. **349 处非法 `status_tags` 标签** —— 标签白名单从代码常量提升到 `rules/publication.yml`（唯一事实来源），代码只读不写。
2. **`item_master_full` 缺板级溯源** —— `package_sha` 从条目溯源的唯一 SHA 回填；`meta.provenance` 照同源先例补 v3 冻结工作副本锁。
3. **`item_master_full` 缺行级定位链（30252 条）** —— 溯源事实其实齐全，只是自建工具写的是**原生字段名**（FID / entry / row_key / row_offset …），与契约规范名不一致。新增修复器 mode `normalize_native_fields`，**规则驱动**地映射，取值来源逐条声明在 `rules/provenance_fixes.yml`，来源缺失就跳过不伪造。

结果：契约错误 **186,627 → 0**，全部 30,252 条规范化，零跳过。

## 怎么用

**只想浏览：**

```bash
git clone https://github.com/lespre/lifeafter-toolkit.git
cd lifeafter-toolkit/02_wiki/web
python -m http.server 8080
```

**用自己设备重建：**

```bash
export LA_CLIENT_ROOT=/path/to/your/client
export LA_ROOT=/path/to/repo
# 装依赖 → 建索引 → 物化还原树 → 解码 → 建板 → 发布
python 02_wiki/web/tools/checks/clone_repro_check.py   # 五关验收
```

详见 README「从零复现 wiki」章节。
