一、它是什么

甲虫无人机是游戏里的一款战术无人机（tactical drone）。它的完整中文名仅出现在 drone_skill_mapping_data_chs.py 的 setting_text 字段，对应 key 270439，是无人机技能映射表里 setting_pos = 14（序号最大）的一档。它关联 3 个技能（270439 / 270440 / 270441），并带有手动 BUFF 25311 与自动 BUFF 25312。

关键判断：它的 3 个技能的图标都指向 icon_dujiaoxianhudun_skill.png（独脚仙护盾），即护盾型无人机。现已从 skill_data / skill_stage_data_5408 / monster_data_220 全链路解出真实效果：甲虫 = 独角仙无人机，3 技能（基础/高阶/典藏）各召唤一面 5000 HP、持续 10 秒、覆盖 500 范围的护盾实体（详见第三节）。
两套无人机别混：甲虫无人机属于「战术无人机」子系统（drone_skill_mapping_data，key 270xxx）；而 wiki 已有的 drone_catalog 总表（287 条）是「机体无人机」（drone_id 180000+，基础/医疗/光盾/电弧…）。战术无人机有技能映射，机体无人机有涂装/典藏版。两者 ID 体系不同。

五、仍待解开项（按铁律精确否定，不猜）

  • BUFF 25311 / 25312（手动/自动）：仅被 drone_skill_mapping_data 的 manual_buff/auto_buff 引用。字节级全树扫描确认：25311/25312 的 4 字节小端命中只出现在 buff_data_kj1 / buff_data_yk 这两个 0x73 加密分服表里（decode_73_table 报 Bindict73Error：既非裸 7b/fb 体、zlib 解压也产不出合法表体）；经典 buff_data（键范围 4~743659）与全部可解码候选表均无此二键。结论：其增益数值锁在加密分服 buff 表里，当前工具不可解。旁证：经典 buff_data_chs.py 含 UI 提示串「无人机玩家点击独角仙技能」——独角仙无人机技能按钮确存在于 UI，但 25311/25312 的具体增益数值不可读。
  • 获取方式：270439 在 2544 张 shop/lottery/activity/item/exchange/gift/reward/quest 候选表的字段值中经解码验证均为 0 真实引用（场景刷怪表里的 4 字节小端命中是数字巧合）；仅在 new_pve_monster_attr_data key=270439 作为护盾实体的 PVE 属性出现。drone_catalog 机体总表 0 条；逐机基础配置 drone_base_conf 为 0x73 加密不可解。结论：获取途径在 11-12 本地可解码配置中未定义（可能服务端下发或尚未实装），不可解。
  • 已解出项：技能真实效果（第三节）已全链路解出——甲虫=独角仙无人机，3 技能各召唤 5000HP/10s/范围500 护盾实体（出生附带 buff 5069、免疫 buff 类型 [15]）。
