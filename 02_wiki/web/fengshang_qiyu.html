一、它们是什么

三个名字不是三款独立活动，而是 「风尚绮遇」(hd 3677 / MultiOptionalLotteryGroupHD) 一个组合活动下的三个并列奖池 tab。官方规则原文：「风尚绮遇活动开启！活动包含幻海旖旎、华宴序曲、绮梦绘卷三个奖池」。入口消耗 绮遇物资箱，兑换商店 exchange_shop_id=81，活动期 2026-11-26 ~ 12-10（静态配置，正式服未上线）。

池内头奖 note 统一写成「幻海魅灵时装」，但三个池的头奖道具 ID 各不相同；按归档道具总表对照，正式名分别是 金色奏鸣曲 / 人偶契约 / 幻海魅灵。note 是策划描述，不是道具名。

二、官方规则全文（desc_info_data_chs.py）

  1. 风尚绮遇活动开启！活动包含幻海旖旎、华宴序曲、绮梦绘卷三个奖池，幸存者可参与活动获取时装及其他丰富奖励。
  2. 幸存者可以通过购买绮遇物资箱在风尚绮遇活动中获得奖励。
  3. 幸存者可在奖池中选择心仪的时装大奖。在幻海旖旎、绮梦绘卷奖池中，选择混合奖池，90次以内必得任意时装大奖；选择指定时装，120次以内必得所选时装大奖。在华宴序曲奖池中，选择混合奖池，60次以内必得任意时装大奖；选择指定时装，80次以内必得所选时装大奖。
  4. 同一奖池内支持中途切换时装大奖，尚未触发保底的抽奖进度将在切换后继承；若当前进度已达到切换后目标大奖的保底次数，则下一次抽取必得该大奖。切换仅更换时装大奖，其他稀有奖励及普通奖励的抽取进度不受影响。
  5. 奖池设有重复道具转化机制，具体规则如下： （1）时装大奖：获取已拥有的时装大奖时，将自动转化为绮遇礼包，开启礼包可获得与对应时装价值相匹配的风尚币，具体数量因时装而异。 （2）稀有奖励：获取稀有奖励中的时装道具时，若幸存者仅拥有该时装的头饰或衣服其中一件，将优先获得另一件未拥有的部件，不进行重复转化。仅在该时装的头饰和衣服均已拥有后，再次获取该稀有时装奖励才会自动转化为风尚币。其他支持重复转化的稀有道具，已拥有后再次获取时，将自动转化为风尚币。各稀有道具的具体转化数量详见奖励预览。
  6. 在幻海旖旎奖池中收集时装，可获得绮遇物资箱、限定称号等奖励。以往参与幻海旖旎活动时已领取的对应收集奖励，本次无法再次领取；本次符合领取条件但未领取的收集奖励，将在活动结束后补发。
  7. 限定称号仅可获取一次，重复获得不会产生额外效果。
  8. 幸存者在每个奖池中每日最多可获取1000次随机奖励。
