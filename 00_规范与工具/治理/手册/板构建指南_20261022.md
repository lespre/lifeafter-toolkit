# 基于全量拆包还原树构建 Wiki 板块

## 一句话

Wiki 是「全量拆包的实现层」。第三方只要拿到**还原树**，用 `board_kit` 写一个字段映射脚本，就能产出合规板块——不用碰解表、取池、写 provenance、写 json/js、注册策略这些重复劳动。

## 现状：耦合点在哪（2026-10-22 扫描 338 个站点脚本）

| 耦合 | 脚本数 | 说明 |
|---|---|---|
| 硬编码 `02_wiki/web` | 156 | 路径写死，换目录就崩 |
| 自己解析 `x{` 表体 | 110 | 每个脚本重复 5 行取 body |
| 自己调 `decode_table_rows` | 106 | 同上，且各自处理 CHS 池 |
| 直接读 `com/cdata` | 72 | 写死表目录，不认还原树版本 |
| 直接写 `data/boards/` | 130 | 各自拼 json/js，格式不一致 |
| 写 `manifest.js` / `publication_policy` | 21 / 26 | 发布口径分散 |
| 硬编码 sha256 | 13 | 换包即失效 |

结论：**解码层已经有库，但没有「板块层」的库**，所以每个板块脚本都在重写中间层。

## 板块契约

一个板块 = 一个 JSON：

```json
{
  "meta": {
    "name": "板块名",
    "category": "二、战力类 / （零）核芯类",
    "package_sha": "<64 位 sha256>",
    "evidence": "structure",
    "provenance": {
      "contract_version": 3, "audit_status": "passed",
      "contract": "frozen-audited-artifact",
      "source_locks": [{"source_id": "documents-py314-current", "role": "primary",
                        "path": "...", "sha256": "...", "bytes": 0, "mtime_ns": 0}],
      "source_scope": {"cross_source_policy": "no-cross-source-field-join",
                       "integer_join_policy": "no-equal-integer-join",
                       "runtime_final_policy": "unknown-unless-runtime-proven"}
    }
  },
  "items": [
    {"id": "...", "name": "...", "evidence_level": "static/candidate",
     "status_tags": ["static config"],
     "provenance": {"source_id": "...", "source_lock_sha256": "...",
                    "table": "...", "row_key": "...", "field_refs": ["..."],
                    "name_source": "chs-pool", "upstream": {...},
                    "locator_chain": {"steps": [{"kind": "decoded-table-row", ...}]}}}
  ]
}
```

**硬规则**

- `provenance.table` 必须是真实存在的表；`row_key` 必须是真实行键。
- 拿不到行键的条目：`status_tags: ["table-absent"]` + `evidence_level: "unresolved"`，**不要编 provenance**。
- 同一 `id` 不得重复。
- `package_sha` 取自源包锁，`board_kit` 自动填。

## 最小示例

```python
from toolkit_core.board_kit import Board, Tree

tree = Tree()                                   # 自动找最新 pe_* 还原树
rows = tree.rows("weapon_skin_data")            # 解表 + CHS 池

b = Board("weapon_skin_demo", "武器皮肤示例", "一、时装类 / （二）武器皮肤", tree=tree)
for r in rows:
    b.add(id="ws_" + str(r["key"]),
          name=tree.value(r, "name", "?"),
          table="weapon_skin_data", row_key=r["key"],
          field_refs=["name"],
          fields={"grade": tree.value(r, "grade")})
b.write()                                       # 校验 + 写 json/js
```

## CLI

```bash
python la.py board run tools/build_kill_broadcast_kit.py   # 跑构建脚本
python la.py board check kill_broadcast                    # 校验一个板块
python la.py web build                                     # 重建 manifest（发布前）
```

`board check` 校验：meta 必填、package_sha 长度、id 唯一、provenance 八字段。

## 第三方接入步骤

```
1 拿到还原树（01_索引与产物/41_还原树/pe_*）+ 客户端源包
2 pip install -r 00_规范与工具/工具/requirements.lock.txt
3 设 LA_ROOT 指向项目根（或让脚本自动探测）
4 写自己的 builder：Tree().rows("表名") → Board().add(...) → write()
5 la.py board check <id> → la.py web build
```
