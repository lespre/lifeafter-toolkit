## Q1｜颜色通道序：**`argb`**（alpha 在列 0）

**样本**：两皮肤全部节点 —— 1110177 91 节点（31 个有 `color_track`）、1110171 48 节点（11 个）。**多键轨道（可判据）28 + 7 条**；单键常数轨道 18 + 11 条（无法判方向，另列）。

**四条逐轨判据 + 两条皮肤级判据**（每条轨道两序各算一次，多数投票）：

| 判据 | 定义 | 1110177 | 1110171 |
|---|---|---|---|
| C1 alpha 单调性 | 候选 alpha 列"同向步占比" | rgba 胜 7 / argb 1 | tie 1 / argb 5 / rgba 1 |

| C4 RGB 色相跳变 | 相邻键帧色相跳变总和（越小越像一条颜色渐变） | argb 11 / rgba 2 | argb 6 / rgba 0 |

**逐条判定汇总**：1110177 **argb 17 / tie 10 / rgba 1**；1110171 **argb 5 / tie 1 / rgba 1**（无一条轨道净判 rgba）。

**最强单点证据（可当场复核）** —— 1110177 `L_g_爆点`（Sprite，6 键）：
```

rgba: alpha = 224→178→144→100→63→13（单调）  但 RGB = 青绿白→暗青 (0,255,248)→(0,76,57)，色相跳变 174°
```

- 语义旁证（不作证、仅对照）：1110177 的源节点名是 `L_模型_顶黄 / L_模型_枪口黄 / M_模型_金线1`，argb 下 RGB 聚在 **44°（金/琥珀）**，与名字一致；rgba 下聚在 129°（绿）。

|---|---|---|

```
if (SprSpeedRate > 0)  fi = floor(age * SprSpeedRate) mod N     // 帧/秒（单位：fps）

```
