## 3. 判据定义（可复现，全部写进 JSON `criteria`）

**硬结构判据**（3 条必须同时成立）：
1. **尺寸**：DDS 尺寸 == `.spr` 声明表尺寸（512² / 256²）。
2. **透明缝**：对每条内部格线 `x = k·pitch_x`（k=1..nx-1）取 **3 px 窄带**（`x-1 .. x+1`）的 alpha 均值；y 同理；令 `seam_max` 为所有格线的最大值，要求 **`seam_max ≤ 0.05`**。
3. **格数**：按 pitch 切格，格 alpha 均值 ≥ **0.002** 记“非空”，要求**非空格数 == nx·ny**（16 / 16 / 4），不允许明显空格。

**内容判据**（与负样本的数值分离，用于打散同尺寸噪声）：
- `edge_density = mean(|∇alpha|) / mean(alpha)`（逐格后取均值）→ 细枝/细线**高**；
- `solidity = area(alpha>0.5) / area(bbox(alpha>0.5))`（逐格后取均值）→ 实心团块**高**、细线**低**；
- `periodicity` = 单元格 alpha 列均值的一维自相关在 `lag≥4` 的最大峰值 → 蜂窝/网点**高**；
- 过滤规则：**`edge_density ≥ 2×负样本` 且 `solidity ≤ 0.8×负样本` 且 `alpha_hi_frac ≤ 负样本`**（细笔画 vs 烟雾/蜂窝/网点）。
