## 4. 可量化的验收口径（测量窗口由 Lead 统一安排；本任务未开浏览器）

**同会话、固定布局、稳定性门 N≥5**：

1. **固定布局**：`--window-size=1400,1000`、`--force-device-scale-factor=1`、载入后 `WikiWeaponViewer.__hidePanels(true)`、`__sfxTime(0)` + `__sfxSeed(0)`、相机用 `default_camera` 不变；记录 `__state().buffer`（应恒 **1178×718**）与 `__state().proj`（武器区投影框，A/B 必须一致）。
2. **门控**：`Network.setCacheDisabled=true`；先以 `__acceptanceReport()` 校验 **每 prim `envMode='source_ibl'`、`ibl_faces=6`、`tex_ready=true`**；再连续调用 `snapshot()`，**取连续 ≥5 帧 PNG sha16 完全相同的帧**做读数（沿用 viewer-auditor task-28 的门）。
3. **三个读数**（在**武器区** = `proj` 框内，按 sRGB 编码后的通道，Rec.709 亮度 L）：
   - **R1 = `%{L>0.5}`**，**R2 = `%{L>0.75}`**，**R3 = 暖色占比 `%{R>0.9 且 G>0.85}`**（与 Lead 给的 P1/P2 读数同口径）。
4. **门限（可证伪）**：当前 P2 = **R1 0.83% / R2 0.03% / R3 0.00%**（p50 0.138、p95 0.282）；目标 P1 = **8.23% / 4.68% / 3.01%**（p50 0.132、p95 0.727）。判定"高光层补上了"= 同会话 A/B 中 **R1 ≥ 2.5%** 且 **R2 ≥ 0.10%** 且 **R3 > 0**，同时 **p50 漂移 ≤ ±0.02**（p50 已对齐，不得靠整体提亮达标）。达不到即证伪该改动对目标指标有效。
5. **禁止**：调曝光 / 灯光强度 / bloom（`viewer.json.exposure`、`hemisphere_intensity`、`key_intensity`、`fill_intensity`、`bloom.strength` 全部保持现值），不得放宽 fail-closed，不得用程序化环境/PMREM 冒充源 cube。
6. **每次读数须同时记录**：`envMode`/`ibl_faces`/`tex_ready`、`uIblScale`/`uIblRot`/`uIblMix` 实际值（`__iblDiag`/`__l0Info` 系列可读）、PNG sha16、两次会话复现性（同 sha16 或给出差异）。
