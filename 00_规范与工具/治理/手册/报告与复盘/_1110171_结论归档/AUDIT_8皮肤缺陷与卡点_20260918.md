## 3. 我推翻 / 未复现的他人结论

1. **推翻「1110129 绑了不存在的 `008_f_m.png` 导致渲染问题」的因果**：运行时绑的是 `008_f_b_m.png`（200）；404 只发生在 manifest 死引用上 → 不是渲染缺陷。
2. **推翻「`t_surfacemap` 未绑=3 个皮肤」**：是 **4 个**，且该槽位不参与渲染绑定 → 不是渲染卡点。
3. **推翻「`metalness≡1` 是源即如此」的全称性**：1110145（源 G=34.65）与 1110152（源 B=71.38）被 repack 强制为 1.0。
4. **未复现「1110152 V=0.150 极暗 / 彩色仅 8.6%」**：我口径（wiki 画布模型区、sRGB 页面像素）得 **val=0.243、彩色像素 85.8%、mean [36.8,60.7,59.0]**。差异可能是口径（整页含背景 / 仅 Sprite 层 / 线性空间）→ 标 **unresolved（口径不可比）**，不判证伪。
5. **未复现「1110024 V=0.416 / S=0.287」**：我测得 **val=0.309、sat=0.501** → 同上，unresolved（口径不可比）。
6. **未复现「1110177 晶体泛白 + 过曝」**：当前构建 white 0.2%、val=0.290、无削顶 → 标 **未复现（可能已修复/修复中）**。
7. **否证「page screenshot sha 变化 ⇒ SFX 可见」这一判定法本身**：1110165 的 SFX 按钮 **disabled**（点击无操作），其页面 sha 仍变化（动画导致）→ 单看 sha 会假阳性。我改用**受控设计**（先取两帧无操作噪声，再取操作后一帧）。

## 4. 最严重 3 个缺陷（按影响排序）

1. **1110145：源参数图离群 → 运行时 roughness≈0.00 全镜面金属**（`014_m.png` R≈0 → `param_repack_014.png` G=0；metalness 被强制 1）。同时它是 7 个皮肤中最暗最冷者（R/B=0.597）。属**数据层**缺陷，派生 repack 把它放大为镜面。
2. **1110165：粗糙度/金属度贴图双缺失（`rm=mm=None`）→ 全材质恒定 metalness=1/roughness=1**，且 `param_repack_165*` 从未生成、manifest 槽位还把 `ParamMap` 错绑到 `165_a.png`、`t_surfacemap` 绑到 `165_m.png`；另 poster 404 → wiki 卡片无图。属**适配层派生资源缺失**。
3. **全 7 皮肤：源贴图色相未被复现（暖色贴图 → 青绿输出）**：cool 像素 67–76%、R/B 0.60–0.80，`param_repack` 把粗糙度写成 R→G 重排后 G∈[2.1,37.0]（≈0.008–0.145）→ 全皮肤近镜面 + 全金属，输出由环境主导。**根因 unresolved**：我用 `__abcProbe('A')`（uIblScale=0）对照后，关环境反而更亮（1110145：`[36,61,61]→[69,88,91]`），与"纯叠加"预期相反，两帧也可能受动画影响 → **不据此下结论**。
