## 3. 源 IBL 公式（已证，照抄即可）

```glsl
// 顶点：不要重复声明 position/modelMatrix/modelViewMatrix/projectionMatrix（Three 会注入）
vUv = uv; vN = normalize(normalMatrix*normal);
vec4 wp = modelMatrix*vec4(position,1.0); vP = wp.xyz;
gl_Position = projectionMatrix*modelViewMatrix*vec4(position,1.0);

// 片元（GLSL3，textureLod 才可用）
float lod = 5.0 + 1.2*log2(max(rough, 0.0019));      // asm 537-539
vec3  V   = normalize(vP - cameraPosition);
vec3  R   = reflect(V, normalize(vN));
float c = cos(u_rotate_angle), s = sin(u_rotate_angle);          // asm 531  cb0[7].w
vec3  Rs = vec3(R.x*s + R.z*c, R.y, -R.x*c + R.z*s);             // asm 535-536,540  绕 Y 轴
vec4  sm = textureLod(uCustomIbl, Rs, lod);                      // asm 541  sample_l
vec3  L  = pow(sm.rgb * sm.a * 16.0, vec3(2.0));                 // asm 542-544  (RGB*A*16)^2
vec3  Lp = L + u_lightmap_factor*(min(L,vec3(1.5))*0.299805 - L);// asm 545-548
Lp *= u_env_day2night_exposure;                                  // asm 549  cb1[239].x
float fres = pow(1.0 - max(dot(N,-V),0.0), 5.0);                 // asm 508-518 菲涅尔
vec3  env  = Lp * mix(vec3(uF0Scale), vec3(1.0), fres);
vec3  col  = albedo*uAlbedoGain + env*uStrength*albedo;          // asm 550  ×菲涅尔
```
**参数级别（关键）**：`u_rotate_angle`/`u_cube_brightness` = **材质级**（`NeoxUBOLocal` @124 / @128）；`u_lightmap_factor`@1384 / `u_env_day2night_exposure`@3824 = **场景级**（`NeoxUBOGlobal1`）。

> **权威偏移表**：不要去猜 offset —— disasm 文件头自带 HLSL 编译器的 `Buffer Definitions` 反编译块，
> 含每项 offset + `[unused]` 标记。直接读 `_known_loop/dxbc_buffer_definitions_blob1_PS.json`（PS 视图）
> 与 `dxbc_buffer_definitions.json`（VS 视图）。PS 里 `NeoxUBOLocal` 35 项中有 **30 项实际使用**，
> `u_env_cube_aabb_max` 标 unused。
> 另注：`u_hdr_luminance@4256` 也在 PS 实际使用列表里 ⇒ **显示链的一部分在 shader 内**，不要全推给后期。

## 5. 坑（踩过的，别再踩）

1. **`toDataURL` 会读到空白缓冲** ✗ —— `WebGLRenderer({preserveDrawingBuffer:false})`（默认）下，合成后缓冲被清 ⇒ 截出来全黑/全同。**症状：四态 SHA 完全相同**。修法：`preserveDrawingBuffer:true` 或同帧 `readPixels` 或 CDP `Page.captureScreenshot`。
2. **ShaderMaterial/GLSL3 不要重复声明 Three 已注入的** `position/normal/uv/modelMatrix/modelViewMatrix/projectionMatrix` ⇒ 编译失败，且**旧 program 会被沿用**（画面看似没变）。
3. **`pow(vec3, vec2)` 非法** ⇒ 必须 `pow(vec3, vec3(2.0))`。**编译日志必须开**：`renderer.debug.checkShaderErrors=true` + `renderer.debug.onShaderError`。
4. **`vMapUv` 只有设了 `map` 才存在**；`vWorldPosition` 在 MeshBasic 片元里不存在（用自带 varying）。
5. **区间删除会静默删掉下游依赖**（曾把 `snapshot()` 整段删掉，导致整轮假失败）。删代码要按行、要 `node --check`。
6. **裸 `THREE` 撞后置 `const`** ⇒ `Cannot access 'THREE' before initialization`；统一用 `state.THREE`。
7. **跨资产借常量 = 污染**（`u_cube_brightness=2.74` 属 003996，不是本皮肤）。判定身份**只用** c159 槽位结构 + NPK `path_id`，**永不按名字**。
8. **GPK 不携带 NPK 的 64 位 path_id**（已证 0/10）；THX/THH 暂停；`lifeafter.exe` 是改过的 UPX（信息块被删，原版 upx 解不了）。
9. **不要凭记忆写 asm 行号** —— 必须重读原文（我曾在 546/549 行写错，并据此得出错误结论）。
10. **`u_refraction_mipmap` 属折射链**，不得当 IBL 的 LOD。
