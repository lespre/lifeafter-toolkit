**注意**：`decoded_size_mismatch` 是已知元数据差异，不能当作解压失败。

### （二）逻辑路径 → NPK file_id

```text
file_id = Murmur3_x86_32(path, 0x77777777) << 32
        | Murmur3_x86_32(path, 0x66666666)
```

路径规则：UTF-8、反斜杠、包内相对逻辑路径；cdata 表的源码标签 `.py` 不等于 NPK 的哈希路径，NPK 中应按同路径的 `.nxs` 试算并在 manifest 内核对。

### （三）FPK

已验证 `32B 文件头 + Zstd 帧流` 的实际边界和逐帧解压。

- `001.fpk` 已完整处理 **40,504 帧**；
- Zstd 帧之间可能有 1–3B 非帧间隔；
- 不可用全文件 magic 搜索替代边界验证；
- 使用 `decompressobj()` + `eof` + `unused_data` 逐帧推进；
- 原始 JSON/二进制段保留为 raw，不伪装成解压失败。

### （四）WPK / IDX

已验证主链：

```text
IDX 记录 → 分卷/slot 文件 → 1DPW 外壳 → 内容解密/解压 → DDS → PNG
```

关键边界：IDX 的 16B hash 是**解密后最终内容 MD5**，不是逻辑路径 ID。双 Murmur3 只能用于 NPK 的路径空间，不能直接代替 WPK/IDX 的实体 hash。

### （五）GPK

已验证 HPGF 变体头、AES 表和 32B 条目结构；现有定向关键词提取器已修正为从正确根目录读取 `res.gpk`。

仍未突破：GPK 条目匿名 ID 到逻辑路径的真实映射算法。已证伪 path_id、CRC32、内容 MD5、SHA1 截断等若干错误假设；因此不能把匿名 GPK 图片按尺寸、颜色、同包关系硬绑成时装海报。

## 四、BinDict：目前最重要的配置解码能力

### （一）已支持的表结构

```text
x{ + body_length + body
body = count + reserved + 端点表/占位 + blob

D6/C6：marker + schema_ref + bitmap_ref + 标量值流
96：marker + schema_ref + 内联 bitmap + 标量值流
0x27：同构序列，可表达 (item_id, quantity) 等列表
0x36：同构映射，可表达 key→value 映射
```

已验证标量类型：ULEB、bool、CHS 引用、jump 引用、zigzag、f32、f64。

### （二）必须遵守的四条规则

1. **base 与 CHS 必须同包配对**。跨 py314 / py3 / legacy 配池会静默造成字段串位。
2. `0x76` 索引 offset 有 direct 与 `<<8` 两个变体，必须由范围校验自适应，不能硬套右移。
3. 行边界必须验证 `marker + schema_ref`；不能在原始字节中裸搜 `D6/96`。
4. `0x27` 同表出现只证明结构关系；要声明“奖池掉落”，必须已闭环到目标 lottery_id 的实际行。

### （三）本轮修正的 KJ1 解码器问题

`reward_pool_data_base` 采用 `76 0b 0b` KJ1 索引。此前工具的 bucket 读取固定最多 200 个 ULEB，会越过当前 bucket 边界，把邻桶内容误拼，造成海量伪行/串池。

已修正：

- `toolkit_core\bindict_table.py`：bucket 改为严格读到**下一 bucket offset**；
- 支持将 KJ1 的真实 D6 row_start 输入 `decode_table_rows()`；
- 行尾 `0x27` 输出为结构化 `inline_groups`，可读取 `(item_id, quantity)`；
- `工具库\06_皮肤定位链\decode_common_lottery.py` 同步修正 bucket 边界。

回归结果：

```text

```

## 七、已证伪 / 禁止重走的路

1. **`entry 2662` 不是铠甲再临奖池配置**。它是共享中文文案池，混有武器库抽奖、喵不可言、核芯词、火刑战驱等多个主题；只能作为显示文本旁证。

3. **390584 / 390588 不是本轮铠甲再临主池**。已用真实 reward_pool 掉落行反证。
4. **内部 reward key 不等于 item_id**。例如 `384508 / 461685` 等中间数不能直接去道具表回填。
5. **不允许跨包配 CHS**。会产生“字段看起来都正常但名字全错”的静默灾难。
6. **不允许用尺寸、颜色、同包、相邻 offset、视觉相似度绑定资源**。
7. **“当前关键词/映射下未找到”不等于资源绝对不存在**。
8. **测试服包中出现配置/特效路径不等于简单生存服已经实装**；服务器分支是玩法结论硬边界。
