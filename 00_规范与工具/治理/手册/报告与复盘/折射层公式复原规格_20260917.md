## 三、折射层公式（逐指令复原）

### 3.1 球面 UV（L465-480）

```asm
465  lt    r5.w, r5.w, -r5.w
466  ge    r6.x, r6.x, -r6.x
467  and   r5.w, r5.w, r6.x
468  movc  r8.x, r5.w, -r4.z, r4.z
469  add   r4.z, -|r8.z|, 1.0
470  sqrt  r4.z, r4.z
471-473  mad ×3   (多项式逼近 asin，系数 -0.018729 / 0.074261 / -0.212114 / 1.570729)
474  mul   r6.x, r4.z, r5.w
475  mad   r6.x, r6.x, -2.0, 3.141593
476-477  lt / and   (符号修正)
478  mad   r4.z, r5.w, r4.z, r6.x
479  add   r8.y, -r4.z, 1.570796                // = π/2 − 纬度
480  mad   r6.xz, r8.xxyx, l(0.159155, 0, 0.318310, 0), l(0.5, 0, 0.5, 0)
```

→ 把方向向量的 `(x, y)` 经 asin 转角度后映射为等距柱状 UV：
`u = x·(1/2π) + 0.5`，`v = y·(1/π) + 0.5`。**两个常数 0.159155 = 1/(2π)、0.318310 = 1/π 是精确值**。

### 3.2 折射采样与调制（L481-492）

```asm
481  sample_l(texture2d) r8.xyz, r6.xzxx, t5, s5, cb0[191].z     // LOD = u_refraction_mipmap
482  mul   r8.xyw, r8.xyxz, r8.xyxz                              // r8 = (s.x², s.y², r8.w, s.x·s.z)
483  add   r4.z, r8.z, r8.z                                      // = 2·s.z
484  mul   r8.xyz, r4.zzzz, r8.xywx                              // r8 = (2·s.z·s.x², 2·s.z·s.y², 2·s.x·s.z²)
485  add   r4.z, cb0[191].y, 1.0                                 // ⊂ u_refraction_contrast
486  add   r4.z, r4.z, cb0[191].y                                // = 2c + 1
487  mad_sat r4.z, r8.x, r4.z, -cb0[191].y                       // = sat(r8.x·(2c+1) − c)
488  mul   r4.z, r4.z, cb0[191].w                                // × u_refraction_brightness
489  mul   r9.xyz, r4.zzzz, cb0[184].xyzx                        // × u_refraction_color
490  mul   r8.xyz, r8.xyzx, r9.xyzx                              // 折射色 = r8 · (k · u_refraction_color)
491  mul   r8.xyz, r3.wwww, r8.xyzx                              // × r3.w（掩码/不透明度）
492  div   r9.xyz, r8.xyzx, cb1[266].xxxx                        // ÷ 场景曝光
```

**可实现的等效伪码**：

```glsl
vec2  uvR = vec2(atan2dir.x * 0.159155 + 0.5,  lat.y * 0.318310 + 0.5);
vec4  s    = textureLod(t_refraction_tex, uvR, u_refraction_mipmap);
vec3  d    = vec3(2.0*s.z*s.x*s.x, 2.0*s.z*s.y*s.y, 2.0*s.x*s.z*s.z);
float k    = clamp(d.x * (2.0*u_refraction_contrast + 1.0) - u_refraction_contrast, 0.0, 1.0)
             * u_refraction_brightness;
refraction = d * (k * u_refraction_color) * mask / sceneExposure;
```

## 四、能否接入？—— **资产合格，但缺一个参数**

| 依赖 | 状态 |
|---|---|
| `t_refraction_tex` ← 候选 `gpk_1230` | ✅ **资产合格**：真实 alpha 0~255 / mean 186.6 / **std 75.0**（有内容），已重解为含 alpha 的 RGBA |
| `u_refraction_color` | ✅ c159 有（cb0[4].xyz） |
| `u_refraction_contrast` | ✅ c159 有（cb0[11].y） |
| `u_refraction_brightness` | ✅ c159 有（cb0[11].w） |
| `u_refraction_rotation` | ✅ c159 有 |
| **`u_refraction_mipmap`** | ❌ **c159 里没有** → 引擎默认值，未知 |
| `cb1[266].x`（场景曝光） | ❌ 运行时场景常量 |
| `r3.w`（掩码/不透明度） | ⚠ 需回到 L460 之前追它的来源 |

**结论**：公式**已复原**，资产**唯一合格**的那张（`gpk_1230`）也在手；
但 **`u_refraction_mipmap` 与场景曝光两个量静态不可得**，`r3.w` 掩码来源还需再往上追一层。

→ **不擅自接入**：可实现的只是"公式 + 一个未知 LOD + 一个未知除数"，
贸然用默认值等于自拟参数。下一步应先追 `r3.w` 来源，并确认 `u_refraction_mipmap`
是否在其他快照/其他皮肤里有取值可参考。

## 五、顺带确认的两条事实

1. **`t5` 就是折射图** —— 与 `t_refraction_tex` 的槽位指派一致，且 UV 是**球面等距柱状**而非网格 UV，
   这也解释了为何用网格 UV 找不到它。
2. **`u_rotate_angle` 只用于 IBL 采样方向**（L532 sincos → L536-537 dp2），
   与折射链**无关** —— 报告 §3「两条链分离」成立。
