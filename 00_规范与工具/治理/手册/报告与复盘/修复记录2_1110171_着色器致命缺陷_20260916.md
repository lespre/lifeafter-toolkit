## 二、缺陷 5：GLSL 保留标识符（致命）

`weapon_skin_viewer.js` 的 IBL 注入体用了 **10 个双下划线标识符**：
`__rough` `__lod` `__R` `__c` `__s2` `__Rr` `__sm` `__L` `__Lc` `__env`

**GLSL ES 3.00 保留含连续两个下划线的标识符**，编译器连「声明」本身都拒绝：

```
ERROR: 0:1849: '__rough' : identifiers containing two consecutive underscores (__)
                are reserved as possible future keywords
ERROR: 0:1850: '__rough' : undeclared identifier
ERROR: 0:1854: 'textureLod' : no matching overloaded function found   ← 级联
... 共 43 条 ERROR
program_info_log: 'Fragment shader is not compiled.'
```

后果链：program invalid → `WebGL: INVALID_OPERATION: useProgram: program not valid` ×1604
→ 这些材质的 draw call 全部空操作 → **武器一个像素都不画**（画面只剩背景房间）。

**修复**：10 个标识符整体改名为非保留前缀 `q_`，**表达式与系数一字未动**。

> 这解释了为什么先修 `pow(vec3,vec2)→vec3(2.0)` 后画面 sha 逐字节不变：
> 那个修法**正确但不够** —— 修掉 1 类错误后还剩 `__` 保留名与下面缺声明 2 类，
> 程序依旧 invalid，所以画面确定性不变。

## 三、缺陷 6：`uIblStrength` 用了却从未声明

注入体末尾 `gl_FragColor.rgb += ... * uIblStrength`，但前置声明串只含
`uCustomIbl / uIblRot / uIblMix / uIblScale` —— **没有 `uIblStrength`**。
在上一行只是给它**赋值**，从未声明。

```
ERROR: 0:1859: 'uIblStrength' : undeclared identifier
```

三臂实验证明它是**独立的第二个错误**：
改名后仍剩这一条；改名 **+** 补声明 → `ok=True, 0 ERROR`。

**修复**：声明串补 `uniform float uIblStrength;`。

## 四、缺陷 7：注入与 three 自身 IBL 重复计入环境能量

修完 5、6 后材质终于绘制，但**整屏过曝发白**。原因：

```glsl
gl_FragColor.rgb += q_env * uIblStrength;   // 在 three 的 PBR 结果上「累加」
```

而 `MeshStandardMaterial` **自身已用同一个 `envMap` 算过一遍 IBL** → 环境能量计两遍。
lab 里不炸是因为 lab 用裸 `ShaderMaterial`，其 `col = ...` 是**替换**；且 lab 的公式还
含 viewer 缺失的三项（交接手册 §3 原文）：

| §3 项 | viewer 原状 |
|---|---|
| `fres = pow(1-dot(N,-V),5)` 菲涅尔 | ❌ 缺失 |
| `env *= mix(vec3(F0), vec3(1), fres)` | ❌ 缺失 |
| `col = albedo*uAlbedoGain + env*uStrength*albedo` | ❌ 缺 albedo 相乘与 `uAlbedoGain` |

**修复**：按 §3 原文逐项补齐，并把末句由 `+=` 改为与 lab `FS_SRC` 逐项一致的
`gl_FragColor.rgb = q_albedo * uAlbedoGain + q_envF * uIblStrength * q_albedo;`
（`uF0Scale` 默认 0.08、`uAlbedoGain` 默认 0.6 均取自 `lab_src.html` 的 `opt` 默认值，**非自拟**。）

## 五、缺陷 8：曝光项默认值比 lab 大 4 倍

viewer 的 `uIblScale`（对应 asm 549 的 `u_env_day2night_exposure`）默认写 **1.0**，
而 `lab_src.html` 的 `opt.envExposure` 默认是 **0.25**。

**修复**：默认改为 0.25 并注明出处。改后背景恢复正常，不再被 bloom 泛白淹没。
