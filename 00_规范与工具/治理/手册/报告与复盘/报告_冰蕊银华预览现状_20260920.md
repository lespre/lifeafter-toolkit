## 3. "不够亮"的排除过程（都已经做过对照实验）

| 假设 | 实测结果 | 判定 |
|---|---|---|
| 色调映射（ACES）把高光压了 | 换成 `NoToneMapping` 后 p50 变成 **0.4323（更暗）** | ❌ 不是主因 |
| 曝光不够 | 源侧 33 条材质参数里**曝光类 uniform = 0 个** | ❌ 无源依据，不许碰 |
| 方向光不够强 | **把三盏灯全关**，p50 只掉 **0.026** | ❌ 不是主因 |
| 球谐环境光没接 | 接了反而**变暗**（0.4724→0.4099）；且 prim0/3 是 `metalness=1.0` ⇒ 漫反射权重 `(1-metalness)=0` | ⚠️ **对金属本体结构性无效** |
| 环境贴图（cube）没绑上 | 换 cube 会改 **26,386 像素**；三灯全关只掉 0.026 ⇒ cube 是**最强单一贡献项** | ✅ 一直绑着（我先前判断是错的） |

**因此主因指向（尚未完全证实）**：① 反照率（albedo）亮度不足 ② `metalness=1` + `roughness≈0.9` 造成的宽而暗的高光 ③ 立方体贴图能量偏低。
【代理自述】即使把 cube 换成另一套 + 把环境增益取到上限，也只到 p50 0.5592 / 近白 8.33%，**仍差 3.92 倍 / 30.6 个百分点**。

## 5. 未达成的部分 + 卡在哪（最重要的一节）

### 5.1 「辉光」卡在一个空的参数容器
`neox_material.json` 里 5 个部件全部是 `crystal_params: {}`、`source_uniforms: {}`。后果是程序取了**诊断用的兜底色**（不是源值），并且辉光强度 `uEmissiveStrength` 取到 **0** ⇒ 辉光公式算出来**恒为 0**（这就是"开关辉光画面 0 像素变化"的机制）。
源侧本应取的值（档：`source_present_value_unreadable`，即"位置已找到、数值由运行时填"）：

| 项 | 现状（错） | 源侧应取 |
|---|---|---|
| M1(prim1) | 兜底 `[0,0.2118,0.8]` | `u_base_color=[0.0549,0.0549,0.0588,1]`、`u_crystal_color=[0.8039,0.7647,0.7059,1]`、`u_subsurface_color=[0.0824,0.098,0.0196,1]` |
| M4(prim4) | 同上 | `u_base_color=[0.4745,0.4431,0.4196,1]`、`u_crystal_color=[0.0941,0.0784,0.3804,1]`、`u_subsurface_color=[0.2471,0.0314,0.3922,1]` |
| 辉光强度 | **0** | **无适用源值**：`0.7` 落在 `M3 / pbr_weapon`，**不得跨材质复制**；M1/M4 是否存在自己的 emissive 数值 = 未解 |

**更正（v2）**：我此前说"两处自相矛盾"是**错的**。`u_emissive_strength` **并非晶体专属**——`pbr_crystal`、`pbr_subsurface`、**`pbr_weapon` 都声明它**（weapon 已有 13 个变体证据）。因此 `0.7@4198` 的合理归属是 **M3 / pbr_weapon 的候选 emissive 参数**，**不是 M1/M4 晶体辉光强度的证据，禁止跨材质复制**。

**真正的阻塞不是"参数容器为空"，而是运行时没按源 shader family 路由**：源侧 prim1/4 声明 `pbr_crystal`、prim2 声明 `pbr_subsurface`，但生产 manifest 里运行用的 `shader_kind` 仍写成 `weapon`，且已定位的 common 贴图在对应 prim 里仍是 `local_file:null / missing`。链路是：
`源文件已找到 → 生产 manifest 未按材质族路由 → crystal shader 未启用 → crystal_params 无人消费`。
⇒ **此时直接写晶体颜色/强度进去，很可能仍是 no-op。** 必须先解决路由，再谈取值。

### 5.2 「全方位环境光」结构性受限
- `u_env_sh` / `u_default_sh`（球谐环境光，源解析里"各向都有"的那一项）在运行时缓冲里，**静态读不到**；
- 我们查看器的替代做法是"用立方体贴图重建"，实测**反而更暗**（0.4724→0.4099）；
- **更正（v2）**：`metalness=1.0` 是**标量**，但 prim0/3 **确实绑定了 `metalnessMap`（1024×1024）** ⇒ 逐像素有效金属度 `effectiveMetalness = metalness × metalnessMap.B`，**并非恒为 1**（ParamMap 的金属通道不是全白）。所以**不能**推出 `(1-metalness)=0`、"球谐漫反射对武器本体结构性为零"。必须**读取运行时有效 metalness**（或输出该中间量）才能下结论。

### 5.3 「辉光流动」的另外两个硬缺口
- FX 的 **12 个发光模型节点**（翅膀/星点/宝石/glow）源里**既没有可解析贴图、也没有几何缩放** ⇒ 默认被 fail-closed 门挡住**不绘制**（不绕门，避免又画出一坨无据的板）；另有 **2/3 粒子系统**的贴图（`glow\*.tga`）按名字哈希三重搜索全 MISS ⇒ 不画、**零顶替**。
- 结果：源可支撑的可见特效只有 **1 个粒子系统、约 139–140 像素**。

### 5.4 特效跟随的"默认态"验收其实是 FAIL
我在某轮说过"SFX 闸门 OVERALL PASS"——**那个 PASS 是在"强制打开模型层"的情况下拿到的**。默认态（fail-closed 生效）实测 **FAIL**：IoU 0.9306（要求 <0.5）、质心位移 4.2px（要求 ≥20）。**这个结论我作废，不再用它充数。**

## 6. 我推翻过的结论（诚实台账）

完整台账：`03拆包产物/_target_1110025/CORRECTIONS_20260920.md`（共 13 条）。影响最大的几条：

## 7. 已做出的决策（Lead 裁决）

| 决策 | 内容 | 理由 |
|---|---|---|
| 直接光 | **保留手填值**（强度 2.2、方向 `[3,-4,-1]`），但标 `approximate` | 用户裁定"实在没有就手填"。静态数据已穷尽证明**没有数值**，字段位置有字节级证据（`NeoxUBOGlobal1.u_dir_color@336/16B`、`u_dir_direction@352`、`u_shadow_info@320`、`u_pcf_scale@1380`）；RDEF 里字面默认值 **0 个** |
| 环境立方体（IBL cube） | 采用 **`jiayuan02a`**，理由只认**内容证据**（游戏截图背景是明亮冷蓝白室内房间，该 cube 就是室内房间；另一套是暖米柔光箱）；**选哪套仍标未解** | 静态无选择器；**不按"哪个更亮"选** |
| `u_cube_brightness` | **保持 1.0（引擎默认）**，不采用 2.74 | 目标材质根本没声明它；2.74 是按参考图挑的最亮档 = 用户明令禁止的调参 |
| 色调映射 | 维持 **ACESFilmic** | `NoToneMapping` 实测更暗，且两者都无源依据；只把"死配置"修成可读 |
| 展示平台/阴影 | 实现完成但**默认关闭**（负控实测与基线逐项相同） | 无法复刻参考图台面：本相机视线与水平面夹角仅 8.07°，参考图约 20°，三条约束互斥 |
| 禁令（全程遵守） | 不许调曝光 / ACES / bloom / 环境强度 / 灯强度去凑参考图；不许用别的贴图顶替；未定证槽位不许猜 | 32 条材质参数里曝光类 uniform = 0 个，源侧零依据 |

## 9. 仍待处理（按优先级）

1. **先按源 shader family 路由**（实验分支）：M0/M3 → `weapon`、M1/M4 → `crystal`、M2 → `subsurface`。
2. **把 4 张已定证贴图写入对应 prim 的 `local_file + SHA`**（当前它们只是"文件存在、HTTP 可访问"，**不等于已绑定到实际绘制程序**）。
3. **运行时输出每个 prim 的实际 `shader_kind / program / bound textures`**，确认 GPU 真的消费。

## 10. 名词解释（给非工程读者）

| 名词 | 白话 |
|---|---|
| 拆包器 | 把游戏封包（`.gpk/.fpk/.npk`）里的文件解出来、并能按名字找到对应资源的程序 |
| 名字轴 / `path_id` | 游戏用"路径名字的哈希"给资源编号；知道名字就能算出编号、进而找到文件 |
| IBL / 环境立方体 | 一张六面环境图，让金属表面反射出"周围环境"，这是金属看起来亮的主要来源 |
| 球谐环境光（SH） | 用一种压缩方式记录"各方向来的环境光"，让物体的**非金属**部分也有环境亮度 |
| albedo / 反照率 | 材质本身的"固有色"亮度；它决定物体的基础明暗 |
| metalness / roughness | 金属度 / 粗糙度。金属度=1 时，光照几乎全走"反射"，漫反射为 0 |
| tone mapping / ACES | 把高动态范围亮度压进屏幕可显示范围的映射函数；ACES 会把很亮的白压成灰白 |
| `.spr` | 精灵图集描述文件，里面写这一组动画有多少帧、每帧取哪块区域 |
| fail-closed | "没有依据就不画"的安全策略；本项目用来避免画出无据的白板或错色 |
| `u_*` | 着色器的输入参数（uniform），例如 `u_emissive_strength` 控制自发光强度 |
