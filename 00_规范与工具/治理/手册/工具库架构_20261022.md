## CLI：只有一个入口

```bash
python la.py <命令>
```

| 命令 | 作用 |
|---|---|
| `status` | 服务 / 索引 / 数据一眼看 |
| `doctor` | 环境 → 索引 → CLI → 服务 四项自检 |
| `web refresh\|build\|check\|serve\|shot` | 站点数据与页面 |
| `index all` | 拉包 + 重建索引 + 名字回填 |
| `pe check\|best\|resolve\|export` | PE 2D 取图（`.ktx/.dds/.png/.bc7`，高清优先） |
| `pc check\|resolve\|export` | PC 取图（`.bc7` → DDS/BC7） |
| `npk export\|query` | item_icon npk 图标库 |
| `watch device\|cdn\|logcat` | 热更 / 设备监测 |
| **`tool <子命令…>`** | 透传到 `toolkit_cli.py`（见下） |

`tool` 后面就是原来的 toolkit_cli 命令，不用再设 PYTHONPATH：

```bash
python la.py tool tables list
python la.py tool lottery show 390530
python la.py tool atlas list
python la.py tool locate res\weapon.gpk 1225
python la.py tool servers
python la.py tool script <file.py>        # 脚本反编译
python la.py tool bindict-check --lenient
```

## 脚本约定

- **能被别人调用的**放 `00_共享核心/toolkit_core/`，函数化、可被 import。
- **只在命令行跑的**放对应业务目录，文件名用动词开头（`build_` / `check_` / `backfill_` / `wire_`）。
- **一次性探索**不进工具库，写完即归档。
- 同一脚本的迭代不要留 `_v2/_v3`：确定最终版后把旧版移走。
