## 新设备使用

```bash
unzip la-toolkit-v1.3.0-code.zip && cd la拆包项目
unzip la-wiki-data-v1.3.0.zip        # 覆盖到项目根
python 02_wiki/web/tools/build_wiki.py
python 02_wiki/web/tools/wiki_server.py --port 8765
# 打开 http://127.0.0.1:8765/wiki.html
```
