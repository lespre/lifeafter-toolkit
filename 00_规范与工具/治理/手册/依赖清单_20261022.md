# 依赖清单（2026-10-22）

## 运行时

| 依赖 | 位置 | 说明 |
|---|---|---|
| Python 3.12 | `.venv/`（不入库） | 项目全部脚本的运行环境 |
| Python 包 | `00_规范与工具/工具/requirements.lock.txt` | `pip install -r` 即可 |
| Node | 不需要 | 站点是纯静态，无构建步骤 |

## 前端第三方库（已入库）

| 库 | 位置 | 用途 |
|---|---|---|
| three.js | `02_wiki/web/assets/vendor/three/` | 3D 预览（模型/皮肤） |
| GLTFLoader | `assets/vendor/three/addons/loaders/` | GLB 加载 |
| **Spine 3.8 运行时** | `02_wiki/web/assets/spine_runtime/3.8/` | spine 动画播放（`spine-core-3.8.js` + `spine-webgl-3.8.js`） |
| spine 图集数据 | `assets/spine/`（本地） | atlas + json + 贴图页，由 `spine_export.py` 生成 |

> Spine 版本必须与数据一致：游戏这批头像是 **3.8.x**。
> 由于 3.8 导出的 `skins` 是对象、而部分运行时按数组读，
> `spine_view.html` 在加载时会自动把对象转数组（见文件内注释）。
