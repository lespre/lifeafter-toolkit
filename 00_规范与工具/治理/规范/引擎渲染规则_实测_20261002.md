## 二、对**渲染链**的直接约束（逐条怎么用）

| # | 规则 | 对渲染链的含义 |
|---|---|---|
| 1 | `ResourceRoot=".\res"` | PC 侧资源根 = 客户端目录下的 `res` ✓（不是 Documents ✗）；移动端才是 `%DOC_DIR%` ✓ |
| 2 | `UseTextureAtlas="True"` + `UseRuntimeTextureAtlas="True"` | 引擎**会做运行时图集** ⇒ 部分贴图**不以独立文件存在** ✓ ⇒ 「按 .c159 声明路径找独立贴图」命中率天然偏低 ✗ |
| 3 | **`MergeSprite` 只打包 `Regex="ui/item_icon/.*_s.png"`** ✓✓ | ★ **只有 item_icon 这一类被自动合并** ✓ ⇒ 图集问题**只影响 UI 图标**，不解释全部 MISS ✗（这条很重要，别把低命中全推给图集 ✓） |
| 4 | `Group Algorithm="Lines" TextureSize="512" PackingTextureLimit="4"` | 图集布局 = **Lines 算法**、页 512×512、每图最多 4 页 ✓ ⇒ 要复现图集就按这个 ✓ |
| 5 | `Format_PC="RGBA"`（vs `UseAstcTexture`）| **PC 侧纹理 = 未压缩 RGBA** ✓；ASTC 是移动端 ✓ ⇒ 解 PC 贴图**不要按 ASTC 解** ✗ |
| 6 | `LoadSeparateAlphaFile="False"` | ★ **不要去找独立的 alpha 贴图文件** ✗（alpha 在同一张图里 ✓） |
| 7 | `GpuSkinningEnable="True"` | ★ 模型是 **GPU 蒙皮** ✓ ⇒ `.mesh` 的顶点流里应含**骨骼权重/索引** ✓（读网格时要按这个布局 ✓） |
| 8 | `GpuParticle="False"` | 粒子走 **CPU** ✓ ⇒ 特效不依赖 GPU 计算 ✓ |
| 9 | `HardwareInstancing="True"` `LODModelLoading="True"` | 同一模型可能有 **LOD 变体** ✓ ⇒ 取模型时注意 LOD 层级（别把 LOD1/2 当主体 ✗） |
| 10 | `EnableCascadeShadowMap="True" CascadeShadowMapCount="3"` `EnableDepthShadow="True"` `EnableScreenSpaceShadow="True"` | 渲染复现时的光照/阴影配置 ✓（3 级级联阴影 ✓） |
| 11 | `ForceDisableUBO="False"` · `UseMetal="False"` · `DeviceType="2"` · `MultiSample="0"` | 管线参数 ✓（UBO 启用 ✓、无 MSAA ✓） |
| 12 | `FontPath="ui/font/yingwen.ttf"` | UI 字体落点 ✓ |
| 13 | `SharedTextureSize="512"` · `VBSize="65536"` | 共用纹理 512 ✓ / 顶点缓冲 64K ✓ |

## 三、据此修正渲染链的做法（行动项）

```
A. 【停止】"去找独立 alpha 文件"这条路 ✗（规则 6：LoadSeparateAlphaFile=False ✓）
B. 【收窄】图集的锅 ✗：只有 ui/item_icon/*_s.png 被 MergeSprite ✓
   ⇒ 其余资产低命中不是因为图集 ⇒ 回到"名字解析"这个真因 ✓
C. 【检查】PC 侧贴图格式按 RGBA 解 ✓（不要按 ASTC ✗）
D. 【检查】读 .mesh 时按 GPU 蒙皮布局解析（含骨骼权重/索引 ✓）
E. 【检查】取模型时区分 LOD（LODModelLoading=True ✓）
F. 【复现图集时】按 Lines 算法 + 512 页 + 最多 4 页 ✓
```
